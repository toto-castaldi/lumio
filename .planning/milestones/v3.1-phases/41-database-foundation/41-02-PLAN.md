  <action>
Create migration file `supabase/migrations/20260313000004_search_decks_rpc.sql` with a SECURITY DEFINER function:

```sql
CREATE OR REPLACE FUNCTION search_decks(
    p_query TEXT DEFAULT NULL,
    p_tag TEXT DEFAULT NULL,
    p_limit INTEGER DEFAULT 20,
    p_offset INTEGER DEFAULT 0
)
RETURNS TABLE (
    id UUID,
    repository_id UUID,
    subfolder_path TEXT,
    display_name TEXT,
    description TEXT,
    tags TEXT[],
    author TEXT,
    language TEXT,
    card_count BIGINT,
    rank REAL
)
```

Implementation details:

1. **Query logic:** SELECT from deck_index with:
   - When `p_query IS NOT NULL AND p_query != ''`: filter by `di.search_vector @@ websearch_to_tsquery('simple', p_query)` and rank by `ts_rank_cd(di.search_vector, websearch_to_tsquery('simple', p_query))`
   - When `p_tag IS NOT NULL AND p_tag != ''`: filter by `di.tags @> ARRAY[p_tag]` (array containment -- uses the GIN index on tags)
   - Both filters can be combined (AND logic)
   - When neither filter: return all decks ordered by display_name

2. **Card count:** Compute via correlated subquery (per locked decision -- not stored):
   ```sql
   (SELECT COUNT(*) FROM cards c
    WHERE c.repository_id = di.repository_id
    AND c.file_path LIKE di.subfolder_path || '%'
    AND c.is_active = TRUE) AS card_count
   ```

3. **Ordering:** Primary: rank DESC (when query provided), Secondary: display_name ASC

4. **Pagination:** LIMIT p_limit OFFSET p_offset

5. **Security:** Use `LANGUAGE plpgsql SECURITY DEFINER` -- deck_index is publicly searchable, no user-specific filtering needed. Use `(select auth.uid())` pattern to verify caller is authenticated (RAISE EXCEPTION if NULL -- per GENERIC_AGENT.md rule about failing loudly).

6. Use `websearch_to_tsquery` (not `plainto_tsquery`) per research recommendation -- handles Google-style search syntax gracefully.

7. Add COMMENT ON FUNCTION explaining parameters and behavior.

**The change:** Add this condition to EVERY `JOIN user_repositories ur ON ...` clause in both functions:

- When `ur.subfolder_path IS NULL` (existing whole-repo subscriptions): all cards from the repo are included (backward compatible)
