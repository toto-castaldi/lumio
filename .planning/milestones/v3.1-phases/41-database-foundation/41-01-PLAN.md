  <name>Task 1: Create deck_index table with fulltext search</name>
  <files>supabase/migrations/20260313000001_deck_index_table.sql</files>
  <action>
Create migration file `supabase/migrations/20260313000001_deck_index_table.sql` with:

1. **CREATE TABLE public.deck_index** with these columns:
   - `id` UUID PK DEFAULT gen_random_uuid()
   - `repository_id` UUID NOT NULL REFERENCES public.repositories(id) ON DELETE CASCADE
   - `subfolder_path` TEXT NOT NULL (always stored WITH trailing `/`, e.g. `italian-vocabulary/`)
   - `display_name` TEXT NOT NULL
   - `description` TEXT NOT NULL DEFAULT ''
   - `tags` TEXT[] NOT NULL DEFAULT '{}'
   - `author` TEXT NOT NULL DEFAULT ''
   - `language` TEXT NOT NULL DEFAULT 'en'
   - `search_vector` tsvector GENERATED ALWAYS AS (setweight(to_tsvector('simple', coalesce(display_name, '')), 'A') || setweight(to_tsvector('simple', coalesce(array_to_string(tags, ' '), '')), 'B') || setweight(to_tsvector('simple', coalesce(description, '')), 'C')) STORED
   - `created_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
   - `updated_at` TIMESTAMPTZ NOT NULL DEFAULT NOW()
   - UNIQUE(repository_id, subfolder_path) -- one index entry per deck folder per repo

2. **Indexes:**
   - `CREATE INDEX idx_deck_index_search_vector ON deck_index USING GIN(search_vector)` -- fulltext search
   - `CREATE INDEX idx_deck_index_tags ON deck_index USING GIN(tags)` -- tag filtering via @> operator
   - `CREATE INDEX idx_deck_index_repository_id ON deck_index(repository_id)` -- webhook lookup

3. **Trigger:** Reuse existing `update_updated_at_column()` function:
   ```sql
   CREATE TRIGGER set_deck_index_updated_at
       BEFORE UPDATE ON deck_index
       FOR EACH ROW
       EXECUTE FUNCTION update_updated_at_column();
   ```

4. **RLS:** Enable RLS on deck_index. Create policy allowing all authenticated users to SELECT (deck index is public/searchable). Create service role ALL policy for Edge Functions (docora-webhook will upsert).

5. **Comments:** Add COMMENT ON TABLE and COMMENT ON COLUMN for subfolder_path and search_vector.

Use 'simple' tsvector config everywhere (per locked decision -- no stemming for multilingual deck names). The search_vector is a STORED generated column that automatically updates when display_name, tags, or description change.

**Migration 1: `supabase/migrations/20260313000002_user_repositories_subfolder.sql`**

Add subfolder_path column to user_repositories and update the UNIQUE constraint:

1. `ALTER TABLE public.user_repositories ADD COLUMN IF NOT EXISTS subfolder_path TEXT;`
   - NULL means whole-repo subscription (existing behavior preserved)
   - Non-NULL means subfolder subscription (always stored WITH trailing `/`)

2. Drop the old UNIQUE constraint: `ALTER TABLE public.user_repositories DROP CONSTRAINT IF EXISTS user_repositories_user_id_repository_id_key;`

3. Create new UNIQUE index handling NULL correctly:
   ```sql
   CREATE UNIQUE INDEX idx_user_repos_unique
       ON public.user_repositories(user_id, repository_id, COALESCE(subfolder_path, ''));
   ```
   This uses COALESCE to treat NULL as empty string for uniqueness, preventing duplicate NULL subfolder_path rows for the same user+repo.

4. Add COMMENT on the new column explaining NULL vs non-NULL semantics.

**Migration 2: `supabase/migrations/20260313000003_platform_repo_seed.sql`**

Add is_platform column to repositories and seed the lumio-decks repo:

1. `ALTER TABLE public.repositories ADD COLUMN IF NOT EXISTS is_platform BOOLEAN NOT NULL DEFAULT FALSE;`
