Add a `LANGUAGE_WHITELIST` constant and a `serializeYaml` helper function before the request handler:

```typescript
const LANGUAGE_WHITELIST = ["it", "en", "es", "fr", "de", "pt", "ja", "zh", "ko", "ru", "ar"];

interface DeckYamlMetadata {
  display_name: string;
  description: string;
  author: string;
  language: string;
  tags: string[];
}

function serializeYaml(metadata: DeckYamlMetadata): string {
  let yaml = '';
  yaml += `display_name: ${metadata.display_name}\n`;
  yaml += `description: ${metadata.description}\n`;
  yaml += `author: ${metadata.author}\n`;
  yaml += `language: ${metadata.language}\n`;
  if (metadata.tags.length > 0) {
    yaml += 'tags:\n';
    for (const tag of metadata.tags) {
      yaml += `  - ${tag}\n`;
    }
  } else {
    yaml += 'tags:\n';
  }
  return yaml;
}
```

Add a `commit_yaml` case in the switch statement, before the `default` case. Implementation:

1. **Extract fields** from request body: `deck_name`, `display_name`, `description`, `tags`, `language`

2. **Validate deck_name**: Required, must be a string. Use existing `validateDeckName()` on the trimmed value. Return 400 with the validation error if invalid.

3. **Validate display_name**: Required, must be a non-empty string after trimming. Return 400 with `"Missing required field: display_name"`.

4. **Validate description**: Required, must be a non-empty string after trimming. Return 400 with `"Missing required field: description"`.

5. **Validate language**: Default to `"en"` if not provided. If provided but not in LANGUAGE_WHITELIST, return 400 with `"Invalid language: {lang}. Must be one of: {whitelist}"`.

6. **Normalize tags**: Filter to strings only from array, map each to `t.toLowerCase().replace(/\s+/g, "-")`, slice to first 5.

7. **Resolve author from user profile** (server-enforced per locked decision):
   - Query `public.users` table: `supabase.from("users").select("display_name, email").eq("id", userId).single()`
   - Author = `profile.display_name?.trim()`. If empty/null, fallback to email prefix: `(profile.email || "").split("@")[0]`
   - Client-sent author value is IGNORED

8. **Serialize YAML** using `serializeYaml()` with all validated/normalized fields.

9. **Build file path**: `${userId}/${deck_name.trim()}/deck.yaml`

10. **Check if file exists**: `const existing = await getFile(yamlPath)` to get SHA for updates.

11. **Commit**: `await commitFile(yamlPath, yamlContent, commitMessage, existing?.sha)` with message `"[deck-builder] Update deck.yaml for {deck_name}"` or `"[deck-builder] Create deck.yaml for {deck_name}"` based on whether existing file was found.

12. **Return success**: `{ success: true, sha: result.sha, commit_sha: result.commit_sha }`

Important notes:
- Do NOT write to deck_index directly. All deck_index mutations flow through docora-webhook (per locked decision).
- Do NOT use validateUserPath() (it enforces .md extension). The path is constructed from userId + deck_name, which are both validated, so path traversal is not possible.
- The supabase client (`supabase` variable) is already created with user auth context earlier in the handler. Use it for the users table query.
