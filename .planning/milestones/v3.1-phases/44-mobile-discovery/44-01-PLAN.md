  <name>Task 1: Create discovery data layer in @lumio/core</name>
  <files>packages/core/src/supabase/discovery.ts, packages/core/src/index.ts</files>
  <action>
Create `packages/core/src/supabase/discovery.ts` with the following exports, following the exact pattern from `study.ts` (import getSupabaseUrl, getSupabaseAnonKey from './client', import getAccessToken, getUserId from './auth'):

**Types:**

1. `DeckSearchResult` interface matching the search_decks RPC return columns:
   - id: string, repository_id: string, subfolder_path: string, display_name: string, description: string, tags: string[], author: string, language: string, card_count: number, rank: number

2. `DeckSubscription` interface for getUserDeckSubscriptions return:
   - repository_id: string, subfolder_path: string, display_name: string

**Functions:**

1. `searchDecks(query?: string, tag?: string, limit = 20, offset = 0): Promise<DeckSearchResult[]>`
   - POST to `${supabaseUrl}/rest/v1/rpc/search_decks` with body `{ p_query: query || null, p_tag: tag || null, p_limit: limit, p_offset: offset }`
   - Use Bearer token + apikey headers (same as getStudyCardsForSession pattern)
   - Map card_count from BIGINT (arrives as number in JSON)
   - Throw on non-ok response

2. `subscribeToDeck(repositoryId: string, subfolderPath: string): Promise<void>`
   - POST to `${supabaseUrl}/rest/v1/user_repositories` with body `{ user_id: userId, repository_id: repositoryId, subfolder_path: subfolderPath }`
   - Use Prefer: 'return=minimal' header
   - Handle 409 conflict (duplicate) as success silently (per Pitfall 2 from research — user tapped twice quickly)

3. `unsubscribeFromDeck(repositoryId: string, subfolderPath: string): Promise<void>`
   - DELETE from `${supabaseUrl}/rest/v1/user_repositories?user_id=eq.${userId}&repository_id=eq.${repositoryId}&subfolder_path=eq.${encodeURIComponent(subfolderPath)}`
   - Throw on non-ok response

4. `getUserDeckSubscriptions(): Promise<DeckSubscription[]>`
   - Step 1: GET from `${supabaseUrl}/rest/v1/user_repositories?subfolder_path=not.is.null&select=repository_id,subfolder_path` to get raw subscriptions
   - Step 2: If subscriptions exist, GET from `${supabaseUrl}/rest/v1/deck_index?select=repository_id,subfolder_path,display_name` to fetch all deck display names (this is a small table, no filtering needed)
   - Step 3: Build a lookup Map keyed by `${repository_id}:${subfolder_path}` from the deck_index results
   - Step 4: Map each subscription to a DeckSubscription, enriching with display_name from the lookup. If no match found in deck_index (orphaned subscription), fall back to subfolder_path with trailing slash stripped and hyphens replaced with spaces, title-cased (e.g. "italian-vocabulary/" becomes "Italian Vocabulary")
   - Throw on non-ok response for either fetch
   - This two-step approach is needed because user_repositories has no FK to deck_index and PostgREST cannot embed without a FK relationship. Per user decision, Repos screen must show deck display_name (not repo URL or folder path).

5. `getLanguageFlag(languageCode: string): string`
   - Simple lookup from LANGUAGE_FLAGS record mapping ISO 639-1 codes to flag emoji using regional indicator symbols
   - Map: it -> IT flag, en -> GB flag, es -> Spain, fr -> France, de -> Germany, pt -> Brazil, ja -> Japan, zh -> China, ko -> Korea, ru -> Russia
   - Fallback: globe emoji `\u{1F30D}`
