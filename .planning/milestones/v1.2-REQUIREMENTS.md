# Requirements: Lumio

**Defined:** 2026-02-08
**Core Value:** Gli utenti studiano concetti tramite quiz generati dall'AI -- il contenuto viene dai repository Git, le domande vengono generate e pre-cachate dal sistema.

## v1.2 Requirements

Requirements for milestone v1.2 Polish & UX. Each maps to roadmap phases.

### Bugfix

- [x] **BUG-01**: User can view full card content in preview without top cutoff
- [x] **BUG-02**: User sees actual app version in Settings (from @lumio/shared, not hardcoded)

### Branding

- [x] **BRAND-01**: User sees Lumio logo on Login screen (replaces text placeholder)
- [x] **BRAND-02**: User sees Lumio logo icon in Dashboard navigation header
- [x] **BRAND-03**: Landing page displays Lumio logo

### Studio

- [x] **STUDY-01**: User can configure cards-per-session (10/20/50/All) in Settings
- [x] **STUDY-02**: User sees "studying Y of X" count on study ready screen
- [x] **STUDY-03**: Study session ends after configured card limit is reached

### Internazionalizzazione

- [x] **I18N-01**: User can switch app language between IT and EN in Settings
- [x] **I18N-02**: Language preference persists across app restarts
- [x] **I18N-03**: All UI strings (buttons, labels, headers, toasts, empty states) update on language change
- [x] **I18N-04**: Card content and AI-generated questions remain in original language

## Out of Scope

| Feature | Reason |
|---------|--------|
| react-native-svg for logo | Native rebuild required, SDK 54 press event regressions -- use PNG conversion |
| Slider for cards-per-session | Decision paralysis -- use preset radio buttons (10/20/50/All) |
| Card content translation | Educational material must stay in original language |
| RTL language support | No RTL languages planned |
| Translation management platform (Crowdin etc.) | 2 languages, ~84 strings, single developer -- JSON files sufficient |
| Per-screen language switching | Over-engineered for 2-language app |
