**Section 1: upsert_card_review RPC**

Create a `SECURITY DEFINER` PL/pgSQL function `upsert_card_review(p_user_id UUID, p_card_id UUID, p_quality INTEGER, p_content_hash TEXT)` that:

1. Reads current SRS state from `card_review_schedule` for (p_user_id, p_card_id). If no row exists, use defaults: ease_factor=2.5, interval_days=0, repetitions=0.

2. Computes new EF using the exact supermemo formula (ALWAYS applied regardless of grade):
   ```
   new_ef = old_ef + (0.1 - (5 - p_quality) * (0.08 + (5 - p_quality) * 0.02))
   ```
   Floor: GREATEST(new_ef, 1.3). Ceiling: LEAST(new_ef, 2.5).

3. Computes new interval and repetition:
   - If `p_quality < 3` (failure): interval=1, repetition=0
   - If `p_quality >= 3` (success):
     - repetition 0 -> interval=1
     - repetition 1 -> interval=6
     - repetition 2+ -> interval=ROUND(old_interval * old_ef)::INTEGER
     - repetition = old_repetition + 1

4. Caps interval: LEAST(new_interval, 365)

5. Atomic UPSERT into `card_review_schedule`:
   - INSERT with all computed values, `next_review_at = CURRENT_DATE + (new_interval || ' days')::INTERVAL`, `last_reviewed_at = NOW()`, `content_hash_snapshot = p_content_hash`
   - ON CONFLICT (user_id, card_id) DO UPDATE SET all fields from EXCLUDED

IMPORTANT: Use `CURRENT_DATE` (not `NOW()`) for `next_review_at` base to avoid timezone flip bugs. The `next_review_at` column is TIMESTAMPTZ, so adding days to CURRENT_DATE produces midnight of the target date in server timezone.

Add a COMMENT on the function.

```typescript
/**
 * Record a card review and update SRS schedule server-side.
 * The RPC runs SM-2 calculation and upserts card_review_schedule atomically.
 *
 * @param cardId - The card that was reviewed
 * @param quality - SM-2 quality grade (1=incorrect, 4=correct)
 * @param contentHash - Current content hash for stale detection
 */
export async function recordCardReview(
  cardId: string,
  quality: number,
  contentHash: string
): Promise<void> {
  const token = await getAccessToken();
  if (!token) throw new Error('Not authenticated');

  const userId = await getUserId();
  if (!userId) throw new Error('User ID not found');

  const supabaseUrl = getSupabaseUrl();
  const response = await fetch(
    `${supabaseUrl}/rest/v1/rpc/upsert_card_review`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${token}`,
        apikey: getSupabaseAnonKey(),
      },
      body: JSON.stringify({
        p_user_id: userId,
        p_card_id: cardId,
        p_quality: quality,
        p_content_hash: contentHash,
      }),
    }
  );

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Failed to record card review');
  }
}
```
