**supabase/functions/git-sync/index.ts — Filter platform repos from getRepositories (REPO-01):**
In the `getRepositories` function (around line 490-509), after the join query on `user_repositories` -> `repositories`, add a filter to exclude platform repos. The current query is:
```typescript
.from("user_repositories")
.select(`repository:repositories(*)`)
.eq("user_id", userId)
```
Add a nested filter to exclude is_platform repos. Since this is a joined query, the filter must be applied on the repositories table. The approach: after fetching results, filter out any repository where `is_platform === true` in the `.filter()` call on the result array. Specifically, change the return statement from:
```typescript
return (data || [])
  .map(d => d.repository as Repository)
  .filter(r => r !== null);
```
to:
```typescript
return (data || [])
  .map(d => d.repository as unknown as (Repository & { is_platform?: boolean }))
  .filter(r => r !== null && r.is_platform !== true);
```

**supabase/functions/git-sync/index.ts — Filter platform repos from getStats:**
In the `getStats` function (around line 432-485), the repository count includes platform repos linked to the user. Apply the same exclusion. After fetching `userRepos`, filter out platform repos before counting. The join query already fetches `repository:repositories(id, lumioignore_content)` — extend the select to include `is_platform`:
```typescript
.select(`
  repository_id,
  repository:repositories(id, lumioignore_content, is_platform)
`)
```
Then filter before counting:
```typescript
const filteredRepos = (userRepos || []).filter(ur => {
  const repo = ur.repository as { id: string; lumioignore_content: string | null; is_platform?: boolean } | null;
  return repo && repo.is_platform !== true;
});
const repositoryCount = filteredRepos.length;
```
Use `filteredRepos` (not `userRepos`) for the card counting loop as well.
