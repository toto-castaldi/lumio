# Milestone v1.1: Lumio Native

**Status:** SHIPPED 2026-02-08
**Phases:** 1-5
**Total Plans:** 20

## Overview

Migration from dual PWA apps (apps/web + apps/mobile) to a single native Android application (apps/android) with a static bilingual landing page (apps/landing). Backend (Supabase) remained unchanged. CI/CD pipeline rebuilt for APK builds and landing page deployment.

## Milestone Summary

**Key Decisions:**

- react-navigation over expo-router (monorepo incompatibility with pnpm)
- @lumio/core reused as-is (platform-agnostic types and utilities)
- SecureStore adapter for Supabase auth tokens (not AsyncStorage)
- Prev/Next buttons over swipe gestures (ScrollView conflict on device)
- Bottom-sheet modal over fullscreen (Android nav controls covering content)
- Expo config plugin for release signing (android/ is gitignored)
- CDN-loaded libraries in WebView for card rendering (LaTeX + code blocks)

**Issues Resolved:**

- expo-router String→Boolean cast error in pnpm monorepo
- Swipe gesture conflict with ScrollView inside QuizCard
- Fullscreen modal covered by Android navigation controls
- EXPO_PUBLIC_* env vars missing from CI Gradle build step
- Google Cloud OAuth SHA-1 missing for release keystore

**Issues Deferred:**

- expo-router still in package.json dependencies (unused, cleanup in future)
- StudyFAB component created but never rendered (orphaned)
- Landing page screenshot placeholders (real screenshots pending)

**Technical Debt Incurred:**

- Phases 1 and 4 missing formal VERIFICATION.md files
- REQUIREMENTS.md traceability table not updated for phases 4-5
