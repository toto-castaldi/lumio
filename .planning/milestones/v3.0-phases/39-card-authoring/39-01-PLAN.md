       Interface CardState:
       ```typescript
       interface CardState {
         name: string;       // filename e.g. "my-card.md"
         path: string;       // full path e.g. "{deckPath}/my-card.md"
         sha: string;        // GitHub blob SHA for update/delete
         title: string;      // derived from filename (de-slugify: strip .md, replace hyphens with spaces, title case)
         tags: string[];     // empty initially (populated when card is loaded)
         difficulty?: number; // undefined initially (populated when card is loaded)
       }
       ```

       Interface CardContextType:
       ```typescript
       interface CardContextType {
         cards: CardState[];
         selectedCard: CardState | null;
         loading: boolean;
         saving: boolean;
         selectCard: (card: CardState | null) => void;
         createCard: (title: string, content: string) => Promise<void>;
         saveCard: (path: string, content: string, sha?: string) => Promise<{ sha: string }>;
         deleteCard: (path: string, sha: string) => Promise<void>;
         refreshCards: () => Promise<void>;
       }
       ```

       Implementation details:
       - Use `useDeck()` to get `selectedDeck` and `refreshDecks`
       - `refreshCards`: calls `listFiles(selectedDeck.path)`, filters out `.gitkeep`, filters to `.md` files only, maps to CardState (title from filename de-slugify, empty tags/undefined difficulty)
       - useEffect: when `selectedDeck` changes, call `refreshCards()` and clear `selectedCard`
       - `createCard(title, content)`: calls `commitFile(path, content)`, then `refreshCards()`, then `refreshDecks()` (to update card count), then auto-select the new card. Toast success/error via react-hot-toast. Uses i18n `t()` for messages.
       - `saveCard(path, content, sha?)`: calls `commitFile(path, content, sha)`, returns `{ sha: result.sha }`. Toast success. Calls `refreshCards()` after success.
       - `deleteCard(path, sha)`: calls `deleteFile(path, sha)`, then `refreshCards()`, then `refreshDecks()` (card count), clears selectedCard. Toast success/error.
       - Toast error handling: same pattern as DeckContext (`err instanceof Error ? err.message : t('common.error')`)
       - Export `CardProvider` and `useCard` hook
