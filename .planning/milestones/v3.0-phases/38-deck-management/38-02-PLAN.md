    **1. Create DeckContext.tsx** following the existing AuthContext/I18nContext pattern:

    Interface:
    ```typescript
    interface DeckContextType {
      decks: DeckEntry[];
      selectedDeck: DeckEntry | null;
      loading: boolean;        // true during any CRUD operation
      initialLoading: boolean; // true only during first deck list fetch
      cardCounts: Record<string, number>; // deck name -> card count (excluding .gitkeep)
      deckCreatedAt: Record<string, string>; // deck name -> ISO date string (from localStorage)
      selectDeck: (deck: DeckEntry | null) => void;
      createDeck: (name: string) => Promise<void>;
      renameDeck: (oldName: string, newName: string) => Promise<void>;
      deleteDeck: (name: string) => Promise<void>;
      refreshDecks: () => Promise<void>;
    }
    ```

    Implementation:
    - `DeckProvider` component with `useDeck` hook (same pattern as `AuthProvider`/`useAuth`)
    - On mount (useEffect), call `api.listDecks()` to fetch deck list. Set `initialLoading = true` during this fetch. After decks load, fetch card counts in parallel: `Promise.all(decks.map(d => api.listFiles(d.path)))`, filter out `.gitkeep` files from each result, count remaining `.md` files, store in `cardCounts` state as `Record<string, number>` keyed by deck name.

    **localStorage-backed timestamps for sort order (per user decision: "sorted by most recently modified"):**

    The GitHub Contents API does not return modification timestamps for directories, so true server-side "last modified" is not feasible without expensive Git history queries. Instead, use localStorage as a client-side proxy:

    - **localStorage key `lumio-deck-timestamps`:** stores a JSON object `Record<string, number>` mapping deck name to Unix timestamp (ms) of last interaction.
    - On `createDeck(name)`: store `Date.now()` for the new deck name.
    - On `renameDeck(oldName, newName)`: remove the old key, store `Date.now()` for newName.
    - On `deleteDeck(name)`: remove the key for the deleted deck.
    - On `selectDeck(deck)`: update the timestamp for the selected deck (selecting = interacting with it).
    - Helper functions `getDeckTimestamps(): Record<string, number>` and `setDeckTimestamp(name: string, ts: number)` to read/write localStorage safely (try/catch for privacy mode).

    **Sort order:** After fetching decks from the API, sort them by `deckTimestamps[deck.name] ?? 0` descending (highest timestamp first). Decks without a stored timestamp (e.g., created on another device or before this feature) sort to the bottom, alphabetically by name among themselves. This gives the user the "last-edited deck on top" experience per their locked decision.

    **localStorage-backed creation dates (per user decision: "creation info" in main area):**

    - **localStorage key `lumio-deck-created`:** stores a JSON object `Record<string, string>` mapping deck name to ISO date string when the deck was first created.
    - On `createDeck(name)`: store `new Date().toISOString()` for the new deck name.
    - On `renameDeck(oldName, newName)`: move the creation date from old key to new key (preserve original creation date).
    - On `deleteDeck(name)`: remove the key.
    - Expose `deckCreatedAt: Record<string, string>` in the context value. Load from localStorage on mount.

    **CRUD operations:**
    - `createDeck(name)`: set loading, call `api.createDeck(name)`, update localStorage timestamps (set lastTouched + createdAt), refresh deck list (which also refreshes card counts), auto-select new deck, show `toast.success(t('deck.createSuccess'))`, catch errors and show `toast.error()`. Clear loading in finally.
    - `renameDeck(oldName, newName)`: set loading, call `api.renameDeck(oldName, newName)`, update localStorage timestamps (move both lastTouched and createdAt from old to new key), refresh deck list, update selectedDeck if the renamed deck was selected, show toast. Clear loading in finally.
    - `deleteDeck(name)`: set loading, call `api.deleteDeck(name)`, remove from localStorage timestamps, refresh deck list, clear selectedDeck if deleted deck was selected, show toast. Clear loading in finally.
    - `refreshDecks()`: call `api.listDecks()`, sort by localStorage timestamps (descending), update state, then fetch card counts for all decks in parallel.
    - Use `useCallback` for all functions, `useMemo` for the context value (matching AuthContext pattern).
    - `loading` flag disables all CRUD buttons globally to prevent race conditions (per research Pitfall 5).
