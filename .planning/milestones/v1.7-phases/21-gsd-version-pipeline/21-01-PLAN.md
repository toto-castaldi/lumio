1. Read `.planning/STATE.md` from the repo root (use `path.resolve(__dirname, '..', '.planning', 'STATE.md')`)
2. Parse the `Milestone: vX.Y` line using regex `/^Milestone:\s*v?([\d.]+)/m`

4. Generate `packages/shared/src/version.ts` by writing the full file content:

   - Replace the hardcoded VERSION value with the extracted version string
   - Keep the BUILD_INFO structure with process.env fallbacks for buildNumber, gitSha, buildDate
   - Add a header comment: "Auto-generated by scripts/extract-version.cjs from .planning/STATE.md -- do not edit manually"
5. Print the extracted version to stdout (for CI to capture): `console.log(version)`
6. Make the script work from any working directory by resolving paths relative to __dirname

Also update `packages/shared/src/version.ts`:
- Add a comment at the top: "Auto-generated by scripts/extract-version.cjs -- do not edit manually"
- Keep the current VERSION value as-is (it will be overwritten by CI; locally it serves as a dev fallback)
- The file is still committed to git so that local dev works without running the script

Add a convenience script to root `package.json`:
- `"extract-version": "node scripts/extract-version.cjs"` in the scripts section

     ```yaml
       run: |

         echo "version=$VERSION" >> $GITHUB_OUTPUT
     ```
   - Update the "Build release APK" step to use `${{ steps.version.outputs.version }}` for versionName instead of the hardcoded `0.0.0`:
     ```
     -PversionName=${{ steps.version.outputs.version }}
     ```

3. **deploy-functions job**:
   - Replace the existing "Extract version info" step that greps version.ts with the extraction script:
     ```yaml
     - name: Extract version from STATE.md
       id: version
       run: |
         VERSION=$(node scripts/extract-version.cjs)
         echo "version=$VERSION" >> $GITHUB_OUTPUT
         echo "build_number=${{ github.run_number }}" >> $GITHUB_OUTPUT
         echo "git_sha=${GITHUB_SHA::7}" >> $GITHUB_OUTPUT
         echo "build_date=$(date -u +%Y-%m-%dT%H:%M:%SZ)" >> $GITHUB_OUTPUT
     ```

   - Keep the existing env vars passed to "Deploy Edge Functions" step (LUMIO_VERSION, BUILD_NUMBER, GIT_SHA, BUILD_DATE) -- they already reference steps.version.outputs correctly.
