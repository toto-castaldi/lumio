Follow the same component structure and styling patterns as SignUpScreen.tsx (existing auth screens use consistent layout).

**Imports:**
- React, useState, useCallback from 'react'
- View, Text, TextInput, TouchableOpacity, StyleSheet, ActivityIndicator, KeyboardAvoidingView, Platform, ScrollView from 'react-native'


**Component: SetPasswordScreen({ route, navigation }: Props)**

**State:**
- `email`: string, initialized from `route.params.email`
- `password`: string, empty
- `confirmPassword`: string, empty
- `showPassword`: boolean, false
- `showConfirmPassword`: boolean, false
- `error`: string | null, null
- `isSubmitting`: boolean, false

**Layout (consistent with existing auth screens):**
1. KeyboardAvoidingView wrapping ScrollView
2. Title: `t('auth.linking.setPasswordTitle')` — large, bold, centered
3. Email TextInput:
   - Pre-filled with route.params.email (Google account email)
   - Editable (per CONTEXT.md: "editable")
   - keyboardType="email-address", autoCapitalize="none"
   - Style: match existing auth screen input styling (borderWidth, borderRadius 8, padding 14, fontSize 16)
4. Password TextInput:
   - secureTextEntry={!showPassword}
   - Right-side eye toggle button (Ionicons eye-outline / eye-off-outline)
   - Placeholder: `t('auth.linking.passwordLabel')`
5. Confirm Password TextInput:
   - secureTextEntry={!showConfirmPassword}
   - Right-side eye toggle button
   - Placeholder: `t('auth.linking.confirmPasswordLabel')`
6. Error text (if error is set): red, below inputs
7. Submit button:
   - Text: `t('auth.linking.setPassword')` (or `t('auth.linking.settingPassword')` when submitting)
   - Background: colors.primary
   - Disabled when isSubmitting

**Submit handler (handleSubmit):**
1. Clear error state
2. Validate: password.length >= 6 — if not, set error `t('auth.linking.weakPassword')`, return
3. Validate: password === confirmPassword — if not, set error `t('auth.linking.passwordMismatch')`, return
4. Set isSubmitting = true
5. try:
   - Call `sendPasswordSetupOtp(email)` from useAuth
   - Show toast: `Toast.show({ type: 'success', text1: t('auth.linking.codeSent') })`
   - Navigate to SetPasswordOtp: `navigation.navigate('SetPasswordOtp', { email, password })`
6. catch:
   - Set error to error message or `t('auth.linking.linkFailed')`
   - Show error toast
7. finally:
   - Set isSubmitting = false

**Style: Use StyleSheet.create with the same visual patterns as existing auth screens:**
- Container: flex 1, padding 24
- Title: fontSize 24, fontWeight 'bold', textAlign 'center', marginBottom 32
- Input container: marginBottom 16, position 'relative'
- Input: borderWidth 1, borderRadius 8, padding 14, fontSize 16

- Error text: color colors.danger, fontSize 14, marginBottom 12
- Button: backgroundColor colors.primary, padding 14, borderRadius 8, alignItems 'center'
- Button text: color '#ffffff', fontSize 16, fontWeight '600'

**Create apps/android/screens/SetPasswordOtpScreen.tsx:**

Follow the exact OTP input pattern from OtpVerificationScreen.tsx (6 digit boxes, auto-advance, paste, shake, auto-submit). Reference that file for the implementation pattern.

**Imports:**
- React, useState, useRef, useEffect, useCallback from 'react'
- View, Text, TextInput, TouchableOpacity, StyleSheet, Animated, Keyboard from 'react-native'
- Ionicons from '@expo/vector-icons'
- Toast from 'react-native-toast-message'
- useAuth from '../contexts/AuthContext'
- useTheme from '../hooks/useTheme'
- useI18n from '../hooks/useI18n'
- NativeStackScreenProps from '@react-navigation/native-stack'
- RootStackParamList from '../navigation/AppNavigator'

**Props type:**
```typescript
type Props = NativeStackScreenProps<RootStackParamList, 'SetPasswordOtp'>;
```

**Component: SetPasswordOtpScreen({ route, navigation }: Props)**

Extract `email` and `password` from `route.params`.

**State and refs (same as OtpVerificationScreen):**
- `digits`: string[] (6 empty strings)
- `inputRefs`: useRef array of 6 TextInput refs
- `shakeAnim`: useRef(new Animated.Value(0))
- `error`: string | null
- `isVerifying`: boolean
- `cooldown`: number (start at 60 — resend cooldown)

**OTP digit input behavior (replicate exactly from OtpVerificationScreen):**
- 6 individual TextInput boxes, each maxLength=1 (first box maxLength=6 for paste support)
- On change: if text.length > 1 (paste), distribute digits across boxes, auto-submit if 6 digits
- On change: if text.length === 1, advance focus to next box
- On keyPress backspace: if current box empty, move to previous box
- Auto-submit when 6th digit entered
- Shake animation on error: Animated.sequence with 4 timing steps (-10, 10, -10, 0)

**Submit handler (handleVerifyAndSetPassword):**
1. Set isVerifying = true, clear error
2. Dismiss keyboard
3. const code = digits.join('')
4. try:
   - Call `verifyPasswordSetupOtp(email, code)` from useAuth
   - Call `setAccountPassword(password)` from useAuth
   - Log session size for SecureStore measurement:
     ```typescript
     const { data: { session } } = await getSupabaseClient().auth.getSession();
     if (session) {
       const sessionSize = JSON.stringify(session).length;
       console.log(`[Auth] Session size after identity change: ${sessionSize} bytes`);
       if (sessionSize > 1500) {
         console.warn(`[Auth] Session size ${sessionSize} exceeds 1500 bytes — monitor SecureStore stability`);
       }
     }
     ```
     Import `getSupabaseClient` from `@lumio/core` for this measurement.
   - Show success toast: `Toast.show({ type: 'success', text1: t('auth.linking.emailPasswordAdded') })`
   - Navigate back to Settings: `navigation.popToTop()` (pops all root stack screens, returns to Main tabs with Settings tab active)
5. catch:
   - Set error to appropriate message (invalid code, expired, etc.)
   - Trigger shake animation
   - Clear digits, focus first input
6. finally:
   - Set isVerifying = false

**Resend cooldown (same pattern as OtpVerificationScreen):**
- useEffect with setInterval decrementing cooldown every second
- Resend button: calls `sendPasswordSetupOtp(email)`, resets cooldown to 60
- Button text: cooldown > 0 ? `t('auth.otp.resendIn', { seconds: cooldown })` : `t('auth.otp.resend')`
- Disabled when cooldown > 0 or isVerifying

**Layout:**
1. Title: `t('auth.linking.verifyEmailTitle')`
2. Subtitle: `t('auth.linking.verifyEmailSubtitle')` + email (bold)
3. 6 digit boxes in a row (same styling as OtpVerificationScreen)
4. Error text if set
5. Verifying indicator (ActivityIndicator) when isVerifying
6. Resend button with cooldown

**Styles:** Match OtpVerificationScreen styling for digit boxes:
- Each box: width 48, height 56, borderWidth 2, borderRadius 8, textAlign 'center', fontSize 24, fontWeight 'bold'
- Active box: borderColor colors.primary
- Error state: borderColor colors.danger
