**AuthContext.tsx — Add identity linking methods and types:**

1. Import `UserIdentity` type from `@supabase/supabase-js` (add to existing import).

2. Add `addPasswordModeRef = useRef(false)` inside AuthProvider. This flag suppresses the PASSWORD_RECOVERY event handler during the add-password OTP flow (prevents recovery navigation guard from activating when the user is already authenticated and adding a password).

3. Guard the existing PASSWORD_RECOVERY handler in `onAuthStateChange`:
   ```
   if (event === 'PASSWORD_RECOVERY' && !addPasswordModeRef.current) {
     setRecoveryState('link_clicked');
   }
   ```

4. Add loading states: `linkGoogleLoading`, `unlinkLoading`, `addPasswordLoading` (all boolean, default false).

5. Add these methods:

   **linkGoogle** — Links a Google identity to an email-only account:
   - Call `GoogleSignin.hasPlayServices()`
   - Call `GoogleSignin.signIn()` — if response.type !== 'success' or no idToken, return silently (user cancelled)
   - Call `GoogleSignin.getTokens()` to get accessToken
   - Call `getSupabaseClient().auth.linkIdentity({ provider: 'google', token: response.data.idToken, access_token: tokens.accessToken })`
   - If error message includes 'already linked', throw new Error('google_already_linked')
   - On success, call `refreshUser()` to update identities
   - Wrap in linkGoogleLoading try/finally

   **unlinkIdentity(identity: UserIdentity)** — Removes an identity:
   - Call `getSupabaseClient().auth.unlinkIdentity(identity)`
   - If error, throw
   - Call `refreshUser()` — CRITICAL: unlinkIdentity does NOT auto-update local user state
   - Wrap in unlinkLoading try/finally

   **refreshUser** — Refreshes user object from server:
   - Call `getSupabaseClient().auth.getUser()`
   - Call `setUser(data.user)` to update AuthContext state

   **sendPasswordSetupOtp(email: string)** — Sends OTP for add-password verification:
   - Set `addPasswordModeRef.current = true` (suppress recovery navigation guard)
   - Call `getSupabaseClient().auth.resetPasswordForEmail(email)`
   - If error, reset `addPasswordModeRef.current = false` and throw
   - Wrap in addPasswordLoading try/finally

   **verifyPasswordSetupOtp(email: string, token: string)** — Verifies OTP during add-password flow:
   - Call `getSupabaseClient().auth.verifyOtp({ email, token, type: 'recovery' })`
   - If error, throw (do NOT reset addPasswordModeRef here — let setAccountPassword handle it)

   **setAccountPassword(password: string)** — Sets password on OAuth-only account:
   - Call `getSupabaseClient().auth.updateUser({ password })`
   - Reset `addPasswordModeRef.current = false`
   - Call `refreshUser()` to update identities
   - If error, reset `addPasswordModeRef.current = false` and throw

6. Add all new methods and loading states to AuthContextType interface and the value object.

**SettingsScreen.tsx — Add connected accounts section below the existing account section:**

1. Import `UserIdentity` from `@supabase/supabase-js`. Import `useNavigation` from `@react-navigation/native` and `NativeStackNavigationProp` from `@react-navigation/native-stack`. Import `RootStackParamList` from `../navigation/AppNavigator`. Import `useCallback` from React.

4. Compute connected accounts from `user.identities`:
   ```typescript
   const identities = user?.identities ?? [];
   const googleIdentity = identities.find(i => i.provider === 'google');
   const emailIdentity = identities.find(i => i.provider === 'email');
   const hasMultipleIdentities = identities.length > 1;
   ```

5. Add handler functions (inside component, using useCallback with t dependency):

   **handleLinkGoogle:**
   - Call `linkGoogle()` in try/catch
   - On success: `Toast.show({ type: 'success', text1: t('auth.linking.googleConnected') })`
   - On error: If `error.message === 'google_already_linked'`, show `t('auth.linking.googleAlreadyLinked')` as error toast. Otherwise show `t('auth.linking.linkFailed')`.

   **handleUnlinkGoogle:**
   - If `!googleIdentity` return
   - Call `unlinkIdentity(googleIdentity)` in try/catch
   - On success: `Toast.show({ type: 'success', text1: t('auth.linking.googleDisconnected') })`
   - On error: `Toast.show({ type: 'error', text1: t('auth.linking.unlinkFailed') })`

   **handleUnlinkEmail:**
   - If `!emailIdentity` return
   - Call `unlinkIdentity(emailIdentity)` in try/catch
   - On success: `Toast.show({ type: 'success', text1: t('auth.linking.emailDisconnected') })`
   - On error: `Toast.show({ type: 'error', text1: t('auth.linking.unlinkFailed') })`

   **handleAddPassword:**
   - Navigate to SetPassword screen: `navigation.navigate('SetPassword', { email: user?.email ?? '' })`
