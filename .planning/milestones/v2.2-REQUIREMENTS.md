## v2.2 Requirements

Requirements for milestone v2.2 Session Limits.

### Session

- [x] **SESS-01**: La RPC rispetta il limite scelto: scadute first (più vecchie prima), poi nuove, totale mai oltre `p_limit`
- [x] **SESS-02**: Con limite "Auto", la RPC restituisce tutte le carte (comportamento attuale invariato)

### Dashboard

- [x] **DASH-01**: Il counter carte mostra il numero di carte della prossima sessione (rispettando il limite), non il debito totale
- [x] **DASH-02**: Con "Auto", il counter mostra il numero reale completo di carte disponibili

### UI

- [x] **UI-01**: Il selettore rinomina l'opzione "Tutte/∞" in "Auto" con icona appropriata
