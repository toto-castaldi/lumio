    Add two new routes to RootStackParamList:

    New screen at `apps/android/screens/CardListScreen.tsx`.

    Props: receives `route.params.repoId` and `route.params.repoName` from navigation.

    Behavior:
    - On mount, call `getRepositoryCards(repoId)` from @lumio/core to fetch all cards
    - Also call `getUserRepositories()` to get the Repository object for image URL resolution (needed by CardDetail)

    - Apply `.lumioignore` filtering using `Deck` class: `new Deck(repository, cards).getActiveCards()`
    - Sort cards alphabetically by title
    - Display in a FlatList with pull-to-refresh
    - Each item rendered as `<CardListItem>` (see below)
    - On card tap, navigate to CardDetail with `{ card, repository }` params
    - Loading state: centered ActivityIndicator
    - Empty state: EmptyState component with icon "documents-outline", title t('cardList.emptyTitle'), subtitle t('cardList.emptySubtitle')
    - Use useTheme for colors, useI18n for translations
    - Header title set from route.params.repoName (the AppNavigator options handle this)

    Navigation type: `NativeStackNavigationProp<RootStackParamList>` from AppNavigator.

      - Tag text: fontSize 12, color colors.primary
    - Right chevron: Ionicons "chevron-forward" size 20, color colors.textSecondary, positioned with flexDirection row + flex 1 on text container
    - Use useTheme for colors
