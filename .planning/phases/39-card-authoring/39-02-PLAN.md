interface CardState {
  name: string;       // filename e.g. "my-card.md"
  path: string;       // full path
  sha: string;        // GitHub blob SHA
  title: string;      // derived from filename
  tags: string[];     // populated on load
  difficulty?: number;
}

  cards: CardState[];
  selectedCard: CardState | null;
  loading: boolean;
  saving: boolean;
  selectCard: (card: CardState | null) => void;
  createCard: (title: string, content: string) => Promise<void>;
  saveCard: (path: string, content: string, sha?: string) => Promise<{ sha: string }>;
  deleteCard: (path: string, sha: string) => Promise<void>;
  refreshCards: () => Promise<void>;
}

export function useCard(): CardContextType;

    1. Create `src/components/CardEditor.tsx`:
       - Uses `useCard()` for saveCard, deleteCard, selectedCard
       - Uses `useI18n()` for t() and locale
       - Uses `useTheme()` for isDark (data-color-mode)
       - Imports parseCard, serializeCard, generateCardTemplate from lib/frontmatter
       - Imports slugify, validateCardTitle from lib/card-validation
       - Imports getFile from lib/api
       - Imports MDEditor, commands from @uiw/react-md-editor
       - Imports katex and katex/dist/katex.css for math preview
       - Imports ConfirmDialog for delete confirmation

       **State management:**
       - `frontmatter: CardFrontmatter` -- current metadata being edited
       - `body: string` -- current markdown body being edited (always string, never undefined)
       - `currentSha: string | undefined` -- SHA from last save or load (undefined for new cards)
       - `currentFilename: string` -- filename (frozen after first save)
       - `hasBeenSaved: boolean` -- tracks whether card has been committed at least once
       - `isNew: boolean` -- true when creating a new card (no selectedCard)
       - `loadingContent: boolean` -- true while fetching card content from GitHub
       - `showDeleteDialog: boolean` -- for ConfirmDialog

       **Load flow (when selectedCard changes):**
       - If selectedCard is set, fetch content via `getFile(selectedCard.path)`
       - Parse with `parseCard(content)` to get frontmatter + body
       - Set state: frontmatter, body, currentSha = file.sha, currentFilename = selectedCard.name, hasBeenSaved = true, isNew = false
       - Show loading spinner during fetch

       **New card flow (when isNew is true, no selectedCard):**
       - Generate template: `generateCardTemplate(locale)`
       - Parse template to get frontmatter + body
       - Set state: frontmatter (from template), body (from template), currentSha = undefined, currentFilename = '', hasBeenSaved = false, isNew = true

       **Save flow:**
       - Validate: title not empty (validateCardTitle), difficulty must be set (not undefined)
       - If validation fails, show inline errors + return
       - Serialize: `serializeCard(frontmatter, body)`
       - Determine filename: if `hasBeenSaved`, use `currentFilename`. Otherwise, `slugify(frontmatter.title) + '.md'`
       - Build path: `{selectedDeck.path}/{filename}` (get selectedDeck from useDeck)
       - Call `saveCard(path, content, currentSha)`
       - On success: update `currentSha` from response, set `currentFilename = filename`, set `hasBeenSaved = true`, set `isNew = false`
       - refreshCards() is called by CardContext.saveCard internally

       **Delete flow:**
       - Show ConfirmDialog (danger variant, reuse from Phase 38)
       - On confirm: call `deleteCard(selectedCard.path, currentSha)`
       - CardContext handles clearing selection and refreshing

       **Filename sync (locked decision):**
       - When `isNew` and `!hasBeenSaved`: show derived filename below title input: `slugify(frontmatter.title).md` (or "untitled.md" if empty)
       - When `hasBeenSaved`: filename is immutable, show it as info text (not editable)

       **MDEditor configuration:**
       - `data-color-mode={isDark ? 'dark' : 'light'}`
       - `value={body}` (always string)
       - `onChange={(val) => setBody(val || '')}` (never undefined)
       - `height={500}` or flexible
       - Responsive preview:
         - Use `window.matchMedia('(min-width: 1024px)')` with a listener for changes
         - Desktop (>=1024px): `preview="live"` (split-pane, editor left, preview right)
         - Mobile (<1024px): controlled `preview` prop toggling between `"edit"` and `"preview"`, with Edit/Preview toggle tabs above the editor
       - Toolbar: 8 buttons array using commands API:
         a. `commands.bold`
         b. `commands.italic`
         c. `commands.code` (inline code)
         d. Custom `mathCommand`: inserts `$$\nx^2 + y^2 = z^2\n$$` (or wraps selection), icon = inline SVG sigma/sum symbol
         e. `commands.title1` (heading)
         f. `commands.unorderedListCommand` (list)
         g. `commands.link`
         h. Custom `imageUrlCommand`: inserts `![alt text](https://)` (or wraps selection with alt text), icon = inline SVG image icon
       - Pass custom commands array to `commands` prop

       **KaTeX math rendering in preview:**
       - Import `katex` and `katex/dist/katex.css`
       - Custom `previewOptions.components.code` that checks for `language-math` className
       - If math language, render with `katex.renderToString(children, { throwOnError: false })`
       - Otherwise render normal `<code>` element

       **Layout:** Flex column:
       - MetadataForm at top (collapsible)
       - Filename display (info text showing current/derived filename)
       - Toggle tabs (mobile only): Edit | Preview buttons
       - MDEditor (fills remaining space)
       - Bottom bar: Save button (left, lumio-accent bg) + Delete button (right, red/danger style). Both disabled during saving.
