       - Import `* as SecureStore` from `expo-secure-store`
       - Keep the same env var validation (EXPO_PUBLIC_SUPABASE_URL, EXPO_PUBLIC_SUPABASE_ANON_KEY) with fail-fast throw
       - Create SecureStoreAdapter implementing StorageAdapter: getItem -> getItemAsync, setItem -> setItemAsync, removeItem -> deleteItemAsync
       - Call `createSupabaseClient(url, anonKey, { storage: SecureStoreAdapter })` to initialize singleton
       - Export `getSupabaseClient` from @lumio/core (re-export for convenience)
       - Keep `import 'react-native-url-polyfill/auto'` at the top

    3. Update `contexts/AuthContext.tsx`:
       - Change import from `import { supabase } from '../lib/supabase'` to `import { getSupabaseClient } from '@lumio/core'` and `import '../lib/supabase'` (side-effect import to ensure initialization)
       - Replace all `supabase.auth.xxx` calls with `getSupabaseClient().auth.xxx`
       - Keep all Google Sign-In logic unchanged (configureGoogleSignIn, signInWithIdToken, GoogleSignin.signOut)
       - This ensures a single Supabase client throughout the app

    CRITICAL: The @lumio/core client uses `flowType: 'pkce'` but this does NOT affect `signInWithIdToken` which bypasses OAuth flows entirely. The auth flow will work identically.

    1. Create `lib/theme.ts`:
       - Define `ThemePreference` type: `'system' | 'light' | 'dark'`
       - Define `lightColors` object: background '#f5f5f5', surface '#ffffff', text '#333333', textSecondary '#6B7280', primary '#3B82F6', primaryLight '#DBEAFE', danger '#ef4444', dangerLight '#FEE2E2', border '#e5e7eb', card '#ffffff'

       - `loadThemePreference()`: AsyncStorage.getItem('@lumio/theme-preference'), return stored value or 'system'
       - `saveThemePreference(pref)`: AsyncStorage.setItem + Appearance.setColorScheme(pref === 'system' ? null : pref)
       - Export `Colors` type as `typeof lightColors`

    2. Create `contexts/ThemeContext.tsx`:
       - ThemeProvider component using useState for preference, useColorScheme() for system scheme
       - Load preference from AsyncStorage on mount via useEffect
       - Compute isDark: preference === 'system' ? systemScheme === 'dark' : preference === 'dark'
       - Compute colors: isDark ? darkColors : lightColors
       - setPreference function: update state + call saveThemePreference
       - Export ThemeProvider and useTheme hook (createContext + useContext pattern)
       - useTheme throws if used outside ThemeProvider

    3. Create `hooks/useTheme.ts`:
       - Simple re-export: `export { useTheme } from '../contexts/ThemeContext'`
       - Convenience import path for screens/components

    4. Update `navigation/MainNavigator.tsx`:

       - Inside MainNavigator function, call `const { colors } = useTheme()`
       - Replace static screenOptions colors with dynamic:

         - tabBarInactiveTintColor: colors.textSecondary
         - tabBarStyle: { backgroundColor: colors.surface, borderTopColor: colors.border }
         - headerStyle: { backgroundColor: colors.primary }
         - headerTintColor: '#ffffff' (keep white for contrast)

       - Import side-effect: `import './lib/supabase'` to ensure @lumio/core initialization before anything else
       - Wrap entire app in GestureHandlerRootView with style={{ flex: 1 }}
       - Add ThemeProvider wrapping NavigationContainer (inside AuthProvider)
       - Add `<Toast />` after StatusBar (outside all providers, at root level)
