<task type="auto">
  <name>Task 2: Rewrite ReposScreen with full repository management</name>
  <files>apps/android/screens/ReposScreen.tsx</files>
  <action>
    Rewrite `screens/ReposScreen.tsx` completely:

    1. Imports:
       - React, useState, useEffect, useCallback from 'react'
       - View, FlatList, Alert, StyleSheet, KeyboardAvoidingView, Platform from 'react-native'
       - getUserRepositories, addRepository, deleteRepository, type Repository from '@lumio/core'
       - Toast from 'react-native-toast-message'
       - useTheme from '../hooks/useTheme'
       - RepoListItem from '../components/RepoListItem'
       - AddRepoForm from '../components/AddRepoForm'
       - EmptyState from '../components/EmptyState'

    2. State:
       - repositories: Repository[] (default [])
       - isLoading: boolean (default true)
       - isRefreshing: boolean (default false)
       - isAdding: boolean (default false)
       - showPatPrompt: boolean (default false)
       - pendingUrl: string (default '') - URL that failed public add

    3. Data fetching (fetchRepos):
       - Call getUserRepositories()
       - Set repositories from result
       - Wrap in try/catch, show Toast.show error on failure
       - Called on mount (useEffect) and on pull-to-refresh

    4. handleAddRepo(url: string, accessToken?: string):
       - setIsAdding(true)
       - try: await addRepository(accessToken ? { url, isPrivate: true, accessToken } : { url })
       - On success:
         - Toast.show({ type: 'success', text1: 'Repository added', text2: 'Cards will sync automatically', position: 'bottom' })
         - setShowPatPrompt(false)
         - setPendingUrl('')
         - Re-fetch repos (await fetchRepos())
       - On error:
         - If error message contains '404' or 'Not Found' or 'private' (case insensitive) AND no accessToken was provided:
           - setPendingUrl(url)
           - setShowPatPrompt(true)
           - Toast.show({ type: 'info', text1: 'Private repository?', text2: 'Enter your Personal Access Token below', position: 'bottom' })
         - Else: Toast.show({ type: 'error', text1: 'Failed to add repository', text2: error message, position: 'bottom' })
       - finally: setIsAdding(false)

    5. handleDeleteRepo(repoId: string, repoName: string):
       - Alert.alert('Delete Repository?', `Remove "${repoName}"? All cards will be deleted.`, [
           { text: 'Cancel', style: 'cancel' },
           { text: 'Delete', style: 'destructive', onPress: async () => {
               try {
                 await deleteRepository(repoId)
                 Toast.show({ type: 'success', text1: 'Repository removed', position: 'bottom' })
                 await fetchRepos()
               } catch (err) {
                 Toast.show({ type: 'error', text1: 'Failed to remove repository', text2: err.message, position: 'bottom' })
               }
             }
           }
         ])

    6. Layout:
       - KeyboardAvoidingView wrapping the screen (behavior: Platform.OS === 'ios' ? 'padding' : undefined)
       - View flex 1, backgroundColor colors.background
       - AddRepoForm at top (outside FlatList): onAdd=handleAddRepo, isAdding, showPatPrompt
         - Wrap in View with paddingHorizontal 16, paddingVertical 12, backgroundColor colors.surface, borderBottomWidth 1, borderBottomColor colors.border
       - FlatList below:
         - data={repositories}
         - renderItem: RepoListItem with onDelete=handleDeleteRepo
         - keyExtractor: item.id
         - onRefresh: handleRefresh (set isRefreshing, fetchRepos, clear isRefreshing)
         - refreshing={isRefreshing}
         - ListEmptyComponent: isLoading ? ActivityIndicator : EmptyState with icon='folder-open-outline', title='No repositories yet', subtitle='Add a GitHub repository above to start studying'
         - contentContainerStyle: repositories.length === 0 ? { flex: 1 } : undefined (center empty state)

    7. The form stays persistent at top. When showPatPrompt is true, the PAT input becomes visible.
  </action>
