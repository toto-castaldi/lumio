**Function signature:**
```sql
CREATE OR REPLACE FUNCTION top_decks()
RETURNS TABLE (
    display_name TEXT,
    subscriber_count BIGINT,
    tags TEXT[],
    language TEXT
)
```

**Implementation details:**
- `LANGUAGE sql` (no plpgsql needed, pure query)
- `SECURITY DEFINER` to bypass RLS (deck_index RLS only allows `authenticated`, but this must work for `anon`)
- Query: SELECT from `deck_index di` with a LEFT JOIN lateral or subquery on `user_repositories ur` to COUNT subscribers
- Subscriber counting: `COUNT(DISTINCT ur.user_id)` from `user_repositories ur` WHERE `ur.repository_id = di.repository_id` AND (`ur.subfolder_path = di.subfolder_path` OR `ur.subfolder_path IS NULL`). The `IS NULL` case covers whole-repo subscriptions which count toward all subfolders in that repo.
- Filter out decks with 0 subscribers: use HAVING or WHERE on the count (only show decks that have at least 1 subscriber)
- ORDER BY `subscriber_count DESC, di.display_name ASC`
- LIMIT 10
- No parameters needed (always returns top 10)

**Permissions:**
After the function, grant execute to `anon` role:
```sql
GRANT EXECUTE ON FUNCTION top_decks() TO anon;
GRANT EXECUTE ON FUNCTION top_decks() TO authenticated;
```

**Comment:**
```sql
COMMENT ON FUNCTION top_decks IS 'Returns the top 10 decks ordered by subscriber count. Public (anon-accessible) for landing page leaderboard. Uses SECURITY DEFINER to bypass deck_index RLS.';
```

**Important:**
- Do NOT require `auth.uid()` -- this is the first public (anon-accessible) RPC in the project
- Do NOT use `RAISE EXCEPTION` for auth -- there is no auth check
- Do NOT include card_count (CONTEXT.md decision: keep it scannable, no card count)
- The function uses SECURITY DEFINER to access deck_index and user_repositories despite RLS

```javascript
var html = '<section class="popular-decks">' +
  '<h2><span lang="en">Popular Decks</span><span lang="it">Deck Popolari</span></h2>' +
  '<ol class="leaderboard-list">';

// For each deck (max 10):
decks.forEach(function(deck, i) {
  var flag = LANG_FLAGS[deck.language] || '\uD83C\uDDEC\uD83C\uDDE7';
  var tags = (deck.tags || []).slice(0, 3);  // Max 3 tags per CONTEXT decision
  var count = deck.subscriber_count || 0;
  var enLabel = count === 1 ? 'subscriber' : 'subscribers';

    '<div class="entry-info">' +
      '<span class="entry-name">' + escapeHtml(deck.display_name) + '</span>' +
      '<div class="entry-meta">' +
        '<span class="entry-subscribers" aria-label="' + count + ' subscribers">' +

      tags.map(function(t) { return '<span class="tag-chip">' + escapeHtml(t) + '</span>'; }).join('') +

});

html += '</ol></section>';
```

```javascript
function escapeHtml(text) {
  var div = document.createElement('div');
  div.appendChild(document.createTextNode(text));
  return div.innerHTML;
}
```
