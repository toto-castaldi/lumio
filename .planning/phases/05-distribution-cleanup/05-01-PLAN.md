<task type="auto">
  <name>Task 1: Add release signing config and dynamic versioning to build.gradle</name>
  <files>apps/android/android/app/build.gradle</files>
  <action>
Modify `apps/android/android/app/build.gradle` to:

1. **Add release signingConfig** inside the existing `signingConfigs` block (after `debug`):
```groovy
release {
    storeFile file('release.keystore')
    storePassword System.getenv('ANDROID_KEYSTORE_PASSWORD') ?: 'android'
    keyAlias System.getenv('ANDROID_KEY_ALIAS') ?: 'androiddebugkey'
    keyPassword System.getenv('ANDROID_KEY_PASSWORD') ?: 'android'
}
```

The fallbacks to debug keystore values allow local development to still work without setting env vars.

2. **Update release buildType** to use `signingConfigs.release` instead of `signingConfigs.debug`:
```groovy
release {
    signingConfig signingConfigs.release
    // ... rest unchanged
}
```

3. **Make versionCode and versionName dynamic** in `defaultConfig`:
```groovy
versionCode (findProperty('versionCode') ?: 1).toInteger()
versionName findProperty('versionName') ?: "1.0.0"
```

This allows CI to pass `-PversionCode=N -PversionName=X.Y.Z` via Gradle properties.

IMPORTANT: Do NOT modify anything else in build.gradle. The react block, dependencies, packaging options must remain exactly as they are. Only touch signingConfigs, buildTypes.release.signingConfig, and defaultConfig version fields.

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Generate release keystore and configure GitHub Secrets</name>
  <action>
The developer needs to perform these one-time setup steps:

**Step 1: Generate keystore locally**
```bash
keytool -genkey -v -keystore lumio-release.keystore \
  -alias lumio -keyalg RSA -keysize 2048 -validity 10000
```
Follow the prompts -- remember the passwords chosen.

**Step 2: Base64 encode the keystore**
```bash
openssl base64 < lumio-release.keystore | tr -d '\n' > keystore.b64
```

**Step 3: Add GitHub Secrets** (Settings -> Secrets and variables -> Actions):
- `ANDROID_KEYSTORE_BASE64` = contents of keystore.b64
- `ANDROID_KEYSTORE_PASSWORD` = store password from step 1
- `ANDROID_KEY_ALIAS` = `lumio`
- `ANDROID_KEY_PASSWORD` = key password from step 1

Also verify these secrets exist (should already be there from web/mobile deploys):
- `SUPABASE_URL` (will be mapped to EXPO_PUBLIC_SUPABASE_URL in CI)
- `SUPABASE_ANON_KEY` (will be mapped to EXPO_PUBLIC_SUPABASE_ANON_KEY in CI)

And add if missing:
- `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` = Google OAuth web client ID

**Step 4: Back up the keystore securely** (password manager, encrypted cloud backup). If lost, users cannot upgrade the app.

**Step 5: Delete local files**
```bash
rm lumio-release.keystore keystore.b64
```
  </action>
  <resume-signal>Type "secrets configured" when all GitHub Secrets are set</resume-signal>
</task>
