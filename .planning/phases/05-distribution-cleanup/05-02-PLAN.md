  <name>Task 2: Update nginx config for static file serving</name>
  <files>conf/nginx-lumio.conf</files>
  <action>
Update `conf/nginx-lumio.conf` to serve static files instead of SPA routing:

1. Replace the `/assets/` location block with a broader static asset cache rule:
```nginx
location ~* \.(css|js|png|jpg|jpeg|webp|ico|svg)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```

2. Replace the SPA `try_files` with static-only:
```nginx
location / {
    try_files $uri $uri/ =404;
}
```

3. Keep the existing `gzip` settings.

The final config should match the pattern from RESEARCH.md (server block with listen 80, server_name, root /var/www/lumio, index, gzip, static cache, try_files =404).
