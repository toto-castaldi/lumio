## Interaction Contract

### Unified List (ReposScreen)

| Interaction | Behavior |
|-------------|----------|
| Pull to refresh | Reloads both repos and shared deck subscriptions |
| Tap shared deck row | Navigate to `CardList` with `repoId` (shared repo ID), `repoName` (display_name), and `subfolderPath` (subfolder_path) |
| Tap repo row | Existing behavior unchanged (navigate to CardList or show error modal) |
| Swipe left on shared deck | Reveal unsubscribe action (80px wide, danger background, trash icon + "Unsubscribe" label) |
| Swipe left on repo | Existing delete behavior unchanged |

### Swipe Unsubscribe

| Property | Value |
|----------|-------|
| Gesture | Swipe left (renderRightActions) |
| Threshold | rightThreshold: 40 |
| Overshoot | overshootRight: false |
| Action width | 80px |
| Action background | `colors.danger` |
| Action icon | `trash-outline` at 24px, color #ffffff |
| Action label | Localized "Unsubscribe" at 12px/600, color #ffffff, marginTop 4px |

### Confirmation Dialog (Alert.alert)

| Property | Value |
|----------|-------|
| Trigger | Tap unsubscribe action after swipe |
| Pre-action | Close swipeable ref before showing alert |
| Style | Native `Alert.alert` (platform dialog) |
| Button 1 | Cancel (style: 'cancel') |
| Button 2 | Unsubscribe (style: 'destructive') |

### Post-Unsubscribe

| Event | Behavior |
|-------|----------|
| Success | Toast success: title + body. Refresh list (fetchRepos). |
| Failure | Toast error: title + error message. |

### Card List (shared deck)

| Interaction | Behavior |
|-------------|----------|
| Screen title | Deck `display_name` (e.g., "Algebra Basics") |
| Card filtering | Filter by `subfolderPath` prefix on card file paths |
| Tap card | Navigate to `CardDetail` with card + repository |
| Pull to refresh | Reload cards |
| Empty state | Reuse existing cardList empty state |

### Italian (it)

| Element | Key | Copy |
|---------|-----|------|
| Shared deck subtitle | `discovery.sharedDeck` | Mazzo condiviso (existing) |
| Unsubscribe dialog title | `repos.unsubscribeTitle` | Disiscriversi da "%{name}"? |

**Important copy change:** The existing `discovery.unsubscribeBody` says "Your study progress will be preserved." This phase introduces atomic deletion of `card_review_schedule` entries on unsubscribe, so the new `repos.unsubscribeBody` must warn about permanent data loss. The `repos.*` namespace is used (not `discovery.*`) because this unsubscribe happens from the Repos screen context.

## States

### Loading State
- Full-screen centered `ActivityIndicator` with `colors.primary`
- Applied to both ReposScreen initial load and CardListScreen initial load
- Existing pattern, no changes

### Empty State (no repos AND no shared decks)
- Existing `EmptyState` component with `git-branch-outline` icon
- Existing copy from `repos.emptyTitle` / `repos.emptySubtitle`
- No changes

### Empty State (shared deck card list has no cards)
- Reuse `EmptyState` component with `documents-outline` icon
- Existing copy from `cardList.emptyTitle` / `cardList.emptySubtitle`

### Refreshing State
- Pull-to-refresh spinner (FlatList `refreshing` prop)
- Existing pattern, no changes

### Error State
- Toast notification for load failures and unsubscribe failures
- Existing pattern, no changes
