3. **Handle missing repository for shared decks:**

   The current code does `repos.find((r) => r.id === repoId)` against `getUserRepositories()`. For shared deck cards, the repository won't be in the user's personal repos list. We need to construct a minimal Repository object so CardDetail navigation works.

   Replace the current `fetchCards` function body with this approach:
   - Keep the `getRepositoryCards(repoId)` call
   - Try `getUserRepositories()` to find the repo
   - If not found (shared deck scenario), construct a minimal Repository object from the card data:
   ```typescript
   const fetchCards = useCallback(async () => {
     try {
       const [allCards, repos] = await Promise.all([
         getRepositoryCards(repoId),
         getUserRepositories(),
       ]);

       let repo = repos.find((r) => r.id === repoId) ?? null;

       // For shared decks, the repo may not be in user's personal repos.
       // Construct a minimal Repository object for CardDetail navigation.
       if (!repo && allCards.length > 0) {
         repo = {
           id: repoId,
           url: '',
           name: route.params.repoName,
           isPrivate: false,
           formatVersion: 1,
           syncStatus: 'synced' as const,
           isAuthError: false,
           createdAt: '',
         };
       }
       setRepository(repo);

       // Apply .lumioignore filtering via Deck
       let activeCards = allCards;
       if (repo && !subfolderPath) {
         const deck = new Deck(repo, allCards);
         activeCards = deck.getActiveCards();
       }

       // Filter by subfolder path for shared deck browsing
       if (subfolderPath) {
         activeCards = activeCards.filter((card) =>
           card.file_path.startsWith(subfolderPath)
         );
       }

       // Sort alphabetically by title
       activeCards.sort((a, b) => a.title.localeCompare(b.title));
       setCards(activeCards);
     } catch (error) {
       console.error('[CardListScreen] fetchCards error:', error);
       Toast.show({
         type: 'error',
         text1: t('cardList.failedToLoad'),
         text2: error instanceof Error ? error.message : t('common.unknownError'),
       });
     }
   }, [repoId, subfolderPath, t]);
   ```

   Note: When `subfolderPath` is set, skip the Deck `.lumioignore` filtering (shared decks don't have per-user `.lumioignore`). The subfolder filter replaces it.
