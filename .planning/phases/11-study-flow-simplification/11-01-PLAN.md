<task type="auto">
  <name>Task 2: Fix Android navbar overlap with safe area bottom inset</name>
  <files>apps/android/screens/StudyScreen.tsx, apps/android/components/study/QuizCard.tsx</files>
  <action>
The Android software navigation bar (gesture bar or 3-button nav) can overlap the bottom of the study content. The study screen uses `SafeAreaView` from `react-native-safe-area-context` which handles top inset, but the bottom action bar and QuizCard scroll content need explicit bottom inset awareness.

**In StudyScreen.tsx:**
- Import `useSafeAreaInsets` from `react-native-safe-area-context`.
- Call `const insets = useSafeAreaInsets()` in the component body.
- On the bottom actions container (the View with `bottomStyles.container`), add `paddingBottom: insets.bottom` to the inline style array so the Next button sits above the Android navigation bar. E.g.: `style={[bottomStyles.container, { backgroundColor: colors.surface, borderTopColor: colors.border, paddingBottom: Math.max(bottomStyles.container.padding || 16, insets.bottom) }]}`. Use `paddingBottom: 16 + insets.bottom` to keep the existing 16px padding PLUS the safe area inset.
  - Note: the `bottomStyles.container` has `padding: 16` which applies uniformly. Change it to `paddingTop: 16, paddingHorizontal: 16, paddingBottom: 16` so we can override just the bottom. Then in the inline style add `paddingBottom: 16 + insets.bottom`.

**In QuizCard.tsx:**
- When the user hasn't answered yet, there's no bottom bar visible -- the QuizCard scroll area extends to the bottom of the screen. In this state, the Android navbar can cover the last answer option or explanation.
- Import `useSafeAreaInsets` from `react-native-safe-area-context`.
- Call `const insets = useSafeAreaInsets()` in the QuizCard component.
- Change the `contentContainerStyle` paddingBottom from the static `32` to `32 + insets.bottom` so the scroll content clears the Android navigation bar.
