    **DeckMetadataForm.tsx:** Create a new component with these characteristics:

    1. **Props:** `deckName: string` (the selected deck's folder name)

    2. **State:**
       - `collapsed` (boolean, default `true` per locked decision)
       - `displayName`, `description`, `language` (strings)
       - `tags` (string[])
       - `loading` (boolean, for initial fetch)
       - `saving` (boolean, for save operation)
       - `loadedRef` (useRef<string>, stores JSON.stringify of loaded state for dirty checking)

    3. **Lifecycle (useEffect on deckName change):**
       - Set loading=true, reset form fields
       - Use a `let cancelled = false` pattern to handle race conditions on rapid deck switching (per research pitfall #2)
       - Call `getDeckYaml(deckName)`:
         - If result is not null: parse YAML content using `parse as yamlParse` from 'yaml' package to extract display_name, description, tags, language. Populate form fields. Store loaded state in loadedRef.
         - If result is null (404): set displayName to deckName (pre-fill from folder name), description to '', tags to [], language to 'en'. Store this as loaded state in loadedRef.
       - On error (not 404 -- getDeckYaml already handles 404 by returning null): show error toast `t('deckMeta.loadError')`, show empty form pre-filled with folder name
       - Set loading=false (only if not cancelled)

    4. **YAML parsing function** (inline or helper inside the component):
       ```typescript
       function parseDeckYaml(content: string): DeckMetadata {
         const data = yamlParse(content) ?? {};
         return {
           display_name: typeof data.display_name === 'string' ? data.display_name : '',
           description: typeof data.description === 'string' ? data.description : '',
           tags: Array.isArray(data.tags) ? data.tags.filter((t: unknown): t is string => typeof t === 'string') : [],
           language: typeof data.language === 'string' ? data.language : 'en',
         };
       }
       ```

    5. **Dirty + valid tracking:**
       - `isDirty`: `JSON.stringify({ display_name: displayName, description, tags, language }) !== loadedRef.current`
       - `isValid`: `displayName.trim().length > 0 && description.trim().length > 0`
       - `canSave`: `isDirty && isValid && !saving && !loading`

    6. **Save handler:**
       - Set saving=true
       - Call `commitYaml(deckName, { display_name: displayName, description, tags, language })`
       - On success: `toast.success(t('deckMeta.saveSuccess'))`, update loadedRef to current state (so isDirty becomes false)
       - On error: `toast.error(err instanceof Error ? err.message : t('common.error'))` -- form stays dirty
       - Set saving=false

    7. **Language dropdown options** (ISO 639-1 matching server LANGUAGE_WHITELIST):

       - When expanded and not loading, show:
         - **Display name**: `<input type="text">` with red asterisk on label. Value: displayName. onChange updates displayName.
         - **Description**: `<textarea rows={3}>` with red asterisk on label, `resize-y` for draggable resize. Value: description. onChange updates description.
         - **Tags**: `<TagInput tags={tags} onChange={setTags} disabled={saving} />`

         - **Save button**: Full-width button at bottom. Disabled when `!canSave`. Text: saving ? t('deckMeta.saving') : t('deckMeta.saveButton'). Styled with `bg-lumio-primary text-white` when enabled, `opacity-50 cursor-not-allowed` when disabled.
       - Red asterisk: `<span className="text-red-500 ml-0.5">*</span>` next to label text for display_name and description.
       - All form inputs use existing lumio design token classes: `rounded-md border border-lumio-border bg-lumio-bg px-3 py-2 text-sm text-lumio-text focus:outline-none focus:ring-2 focus:ring-lumio-primary`
