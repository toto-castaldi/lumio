**For the header logo** (multi-density, small icon):
Same SVG modifications (no signature line, cropped viewBox). Generate 3 density variants:
```bash
convert -background none temp.svg -resize 32x32 apps/android/assets/logo-header.png
convert -background none temp.svg -resize 64x64 apps/android/assets/logo-header@2x.png
convert -background none temp.svg -resize 96x96 apps/android/assets/logo-header@3x.png
```

The signature line MUST be omitted from all generated PNGs because:
1. At small sizes (32px header) it's invisible/confusing
2. On Login screen it's unnecessary visual noise for the brand mark

If ImageMagick SVG rendering is poor quality, try `rsvg-convert` as alternative:
```bash
rsvg-convert -w 128 -h 128 temp.svg > apps/android/assets/logo-login.png
```

Clean up any temp SVG files after generation.
