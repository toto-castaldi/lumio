**index.html changes:**

Replace the header logo link:
```html
<a href="/" class="logo">Lumio</a>
```

With an inline SVG icon + text (logo SVG WITHOUT the signature line, using a tighter viewBox `0 0 400 300` to crop the empty bottom):
```html
<a href="/" class="logo" aria-label="Lumio home">
  <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 300"
       class="logo-icon" role="img" aria-hidden="true">
    <!-- Lumio logo: tri-color pie + 3 rays -->
    <path d="M 200 200 L 200 100 A 100 100 0 0 1 286.6 250 Z" fill="#FFA726"/>
    <path d="M 200 200 L 286.6 250 A 100 100 0 0 1 113.4 250 Z" fill="#FF7061"/>
    <path d="M 200 200 L 113.4 250 A 100 100 0 0 1 200 100 Z" fill="#9C68D4"/>
    <rect x="115" y="-12" width="85" height="24" rx="6" fill="#FFA726" transform="translate(200, 200) rotate(-90)"/>
    <rect x="115" y="-12" width="85" height="24" rx="6" fill="#FF7061" transform="translate(200, 200) rotate(30)"/>
    <rect x="115" y="-12" width="85" height="24" rx="6" fill="#9C68D4" transform="translate(200, 200) rotate(150)"/>
  </svg>
  Lumio
</a>
```

Key decisions:
- Inline SVG (1.3KB) avoids an extra HTTP request. No separate logo file needed in landing deploy.
- Signature line omitted (the `<line>` at y=330) -- too small to be meaningful at 36px display size.
- viewBox cropped to `0 0 400 300` to remove empty space below the graphic.
- `aria-hidden="true"` on SVG because the `<a>` has `aria-label` and visible "Lumio" text.
- `role="img"` for correct semantics.

**styles.css changes:**

Update the `.logo` rule to use flexbox for icon+text alignment, and add a `.logo-icon` rule:

```css
.logo {
  font-size: 1.75rem;
  font-weight: 700;
  color: var(--purple-primary);
  text-decoration: none;
  letter-spacing: -0.02em;
  display: flex;
  align-items: center;
  gap: 0.5rem;
}

.logo-icon {
  width: 36px;
  height: 36px;
}
```

The existing `.logo` style needs `display: flex`, `align-items: center`, and `gap: 0.5rem` added. The new `.logo-icon` class sets the SVG size to 36x36px which is proportional to the 1.75rem text.
