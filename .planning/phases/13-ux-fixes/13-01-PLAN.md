  <name>Task 1: Fix card preview navbar overlap with safe area bottom inset</name>
  <files>apps/android/components/study/CardPreviewModal.tsx, apps/android/components/study/CardContentView.tsx</files>
  <action>
The CardPreviewModal bottom-sheet renders at 80% screen height from the bottom. Content inside (CardContentView's FlatList) has no safe area awareness, so content at the bottom is hidden behind the Android system navigation bar.

Implementation (two files):

1. In `apps/android/components/study/CardContentView.tsx`:
   - Add optional prop `contentPaddingBottom?: number` to `CardContentViewProps`
   - In the `flatListProps.contentContainerStyle`, change from `{ paddingHorizontal: 16, paddingVertical: 8 }` to `{ paddingHorizontal: 16, paddingTop: 8, paddingBottom: 8 + (contentPaddingBottom ?? 0) }`
   - This follows the established Phase 11 pattern: "use paddingBottom: staticPadding + insets.bottom for content near Android navbar"

2. In `apps/android/components/study/CardPreviewModal.tsx`:
   - Import `useSafeAreaInsets` from `react-native-safe-area-context`
   - Call `const insets = useSafeAreaInsets()` inside the component function (after existing hooks)
   - Pass `contentPaddingBottom={insets.bottom}` to the `<CardContentView>` component
  </action>

<task type="auto">
  <name>Task 2: Restyle Settings account section with ACCOUNT header and profile avatar</name>
  <files>apps/android/screens/SettingsScreen.tsx, apps/android/i18n/en.ts, apps/android/i18n/it.ts</files>
  <action>
The "Signed in as" / "Connesso come" section in SettingsScreen uses a plain label+email inside a section card with no section header above it. All other sections (Appearance, Study, Language) have an uppercase section header Text element above their card. Additionally, the user wants a circular Google profile avatar displayed alongside the user info.

**i18n changes:**

1. In `apps/android/i18n/en.ts`, in the `settings` object:
   - Add key `account: 'Account'` (universal term -- will render as "ACCOUNT" via textTransform: 'uppercase' in style)

2. In `apps/android/i18n/it.ts`, in the `settings` object:
   - Add key `account: 'Account'` (same universal term)

**SettingsScreen changes:**

1. Import `Image` from `react-native` (add to existing import).

2. Access Google profile data from Supabase User object. When user signs in via Google, `user.user_metadata` contains `avatar_url` (Google profile image URL) and `full_name` (display name). Extract:
   - `const avatarUrl = user?.user_metadata?.avatar_url as string | undefined`
   - `const displayName = user?.user_metadata?.full_name as string | undefined`

3. Replace the current "User info section" (the first View with label + email, lines ~87-94) with the ACCOUNT section header pattern:

   ```jsx
   {/* Account section */}
   <Text style={[styles.sectionHeader, { color: colors.textSecondary, marginTop: 16 }]}>
     {t('settings.account')}
   </Text>
   <View style={[styles.section, { backgroundColor: colors.surface }]}>
     <View style={styles.accountRow}>
       {avatarUrl ? (
         <Image source={{ uri: avatarUrl }} style={styles.avatar} />
       ) : (
         <View style={[styles.avatarFallback, { backgroundColor: colors.primaryLight }]}>
           <Ionicons name="person" size={24} color={colors.primary} />
         </View>
       )}
       <View style={styles.accountInfo}>
         {displayName && (
           <Text style={[styles.accountName, { color: colors.text }]}>
             {displayName}
           </Text>
         )}
         <Text style={[styles.accountEmail, { color: colors.textSecondary }]}>
           {user?.email ?? t('common.unknownUser')}
         </Text>
       </View>
     </View>
   </View>
   ```

   Note: first section header uses `marginTop: 16` (not 24) since it is at the top of the scroll.

4. Add new styles to the StyleSheet:
   - `accountRow: { flexDirection: 'row', alignItems: 'center', gap: 14 }`
   - `avatar: { width: 48, height: 48, borderRadius: 24 }` (circular)
   - `avatarFallback: { width: 48, height: 48, borderRadius: 24, alignItems: 'center', justifyContent: 'center' }` (icon fallback when no avatar URL)
   - `accountName: { fontSize: 16, fontWeight: '600' }` (display name)
   - `accountEmail: { fontSize: 14, marginTop: 2 }` (email, secondary)

5. Remove old `label` and `email` styles from StyleSheet (no longer used after replacing the old section).

6. The `signedInAs` translation key can remain in the i18n files (not harmful) but is no longer used in the screen. Either remove it from both en.ts/it.ts or leave it -- preference: remove for cleanliness.
  </action>
