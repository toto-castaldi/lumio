Create `apps/android/screens/DiscoveryScreen.tsx` — the main discovery tab screen.

**Imports:**
- React, useState, useCallback, useRef, useEffect from 'react'
- View, FlatList, TextInput, StyleSheet, ActivityIndicator, Alert from 'react-native'
- useFocusEffect from '@react-navigation/native'
- Toast from 'react-native-toast-message'
- searchDecks, subscribeToDeck, unsubscribeFromDeck, getUserDeckSubscriptions, type DeckSearchResult, type DeckSubscription from '@lumio/core'
- useTheme from '../hooks/useTheme'
- useI18n from '../hooks/useI18n'
- DeckCard from '../components/DeckCard'
- TagChipBar from '../components/TagChipBar'
- EmptyState from '../components/EmptyState'
- Ionicons from '@expo/vector-icons'

**State:**
- decks: DeckSearchResult[] (search results)
- subscribedKeys: Set<string> (set of "repositoryId:subfolderPath" keys for O(1) lookup)
- searchText: string (controlled input)
- selectedTag: string | null
- availableTags: string[] (top 10 computed from initial load)
- isLoading: boolean (initial load)
- isSearching: boolean (during search)
- debounceRef: useRef for setTimeout

**Helper:**
- `deckKey(deck: DeckSearchResult | DeckSubscription): string` — returns `${deck.repository_id}:${deck.subfolder_path}` for Set lookups

**Data fetching:**

Use `useFocusEffect` with cancelled flag pattern (same as DashboardScreen):
1. On focus, call `getUserDeckSubscriptions()` to refresh subscription state
2. Build subscribedKeys Set from results using deckKey()
3. On first mount only (when availableTags is empty), also call `searchDecks()` with no query/tag to get all decks
4. From the initial results, compute top 10 tags client-side: extract all tags from all decks, count occurrences, sort descending, take top 10. Store in availableTags.
5. Set decks from results. Set isLoading false.

**Search (300ms debounce per DISC-02):**

`handleSearchChange(text: string)`:
1. setSearchText(text)
2. Clear existing debounce timeout
3. Set new 300ms timeout that calls fetchDecks(text, selectedTag)
4. Set isSearching true

`handleTagSelect(tag: string | null)`:
1. setSelectedTag(tag)
2. Immediately call fetchDecks(searchText, tag) (no debounce on tag selection)

`fetchDecks(query: string, tag: string | null)`:
1. setIsSearching(true)
2. Call searchDecks(query || undefined, tag || undefined)
3. Set decks from results
4. setIsSearching(false)
5. Handle errors: console.error, Toast error

Cleanup debounce timeout on unmount via useEffect return.

**Subscribe (optimistic UI per CONTEXT.md locked decisions):**

`handleSubscribe(deck: DeckSearchResult)`:
1. Optimistically add deckKey(deck) to subscribedKeys Set
2. Show success toast: `t('discovery.subscribed', { name: deck.display_name })`
3. Try: await subscribeToDeck(deck.repository_id, deck.subfolder_path)
4. Catch: revert subscribedKeys (remove key), show error toast `t('discovery.subscribeFailed')`

**Unsubscribe (confirmation dialog per CONTEXT.md):**

`handleUnsubscribe(deck: DeckSearchResult)`:
1. Show Alert.alert with:
   - Title: `t('discovery.unsubscribeTitle', { name: deck.display_name })`
   - Body: `t('discovery.unsubscribeBody')`
   - Cancel button: `t('common.cancel')`, style: 'cancel'
   - Confirm button: `t('discovery.unsubscribe')`, style: 'destructive', onPress:
     a. Remove deckKey(deck) from subscribedKeys
     b. Show toast: `t('discovery.unsubscribed', { name: deck.display_name })`
     c. Try: await unsubscribeFromDeck(deck.repository_id, deck.subfolder_path)
     d. Catch: revert subscribedKeys (add key back), show error toast `t('discovery.unsubscribeFailed')`

**Layout (per CONTEXT.md locked decisions):**

```
<View style={{ flex: 1, backgroundColor: colors.background }}>
  {/* Sticky header */}
  <View style={{ backgroundColor: colors.background, paddingTop: 8 }}>
    {/* Search bar */}
    <View style={{ paddingHorizontal: 16, paddingBottom: 8 }}>
      <View style={searchBarContainer}>  // row, borderRadius: 10, bg: colors.surface, border: colors.border
        <Ionicons name="search" size={18} color={colors.textSecondary} />
        <TextInput
          value={searchText}
          onChangeText={handleSearchChange}
          placeholder={t('discovery.searchPlaceholder')}
          placeholderTextColor={colors.textSecondary}
          style={{ flex: 1, color: colors.text, fontSize: 15 }}
          returnKeyType="search"
          autoCorrect={false}
        />
        {isSearching && <ActivityIndicator size="small" />}
      </View>
    </View>
    {/* Tag chip bar */}
    <TagChipBar
      tags={availableTags}
      selectedTag={selectedTag}
      onSelectTag={handleTagSelect}
    />
  </View>

  {/* Results */}
  {isLoading ? (
    <ActivityIndicator style={{ flex: 1 }} size="large" color={colors.primary} />
  ) : (
    <FlatList
      data={decks}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <DeckCard
          deck={item}
          isSubscribed={subscribedKeys.has(deckKey(item))}
          onSubscribe={handleSubscribe}
          onUnsubscribe={handleUnsubscribe}
        />
      )}
      contentContainerStyle={decks.length === 0 ? { flexGrow: 1 } : { paddingHorizontal: 16, paddingTop: 8, paddingBottom: 16 }}
      ItemSeparatorComponent={() => <View style={{ height: 10 }} />}
      ListEmptyComponent={renderEmptyState()}  // see below
    />
  )}
</View>
```

**Empty states (per CONTEXT.md locked decisions):**

`renderEmptyState()`:
- If searchText is empty AND selectedTag is null AND decks.length === 0 AND !isSearching (no decks exist at all):
  Return `<EmptyState icon="library-outline" title={t('discovery.noDecksTitle')} subtitle={t('discovery.noDecksSubtitle')} />`
- If (searchText or selectedTag) AND decks.length === 0 (search/filter returned nothing):
  Return `<EmptyState icon="search-outline" title={t('discovery.noResultsTitle')} subtitle={t('discovery.noResultsSubtitle')} actionLabel={t('discovery.clearFilters')} onAction={clearFilters} />`

`clearFilters()`: setSearchText(''), setSelectedTag(null), call fetchDecks('', null)
