1. Add a step BEFORE "Deploy to DigitalOcean" that runs `extract-version.cjs` to get the version:
   ```yaml

     id: version
     run: |

       echo "version=$VERSION" >> $GITHUB_OUTPUT
   ```

Important: Do NOT modify any other jobs. Only modify `deploy-landing`.
