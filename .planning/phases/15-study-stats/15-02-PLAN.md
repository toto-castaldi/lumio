**Step 3: Create StudyHistoryScreen** (`apps/android/screens/StudyHistoryScreen.tsx`)

Create a new screen that:
1. Imports `getStudyHistory` from `@lumio/core` and `StudySession` type from `@lumio/core`
2. Uses `useTheme()`, `useI18n()`, `useNavigation()`
3. On mount, calls `getStudyHistory()` to fetch sessions
4. Uses `useLayoutEffect` to set `navigation.setOptions({ headerTitle: t('history.title') })`
5. Renders a `FlatList` of sessions
6. Handles loading state with `ActivityIndicator`
7. Handles empty state using the existing `EmptyState` component with icon `time-outline`, title `t('history.emptyTitle')`, subtitle `t('history.emptySubtitle')`
8. Handles error state with a simple error message and retry

Each session row renders:
- Left side: date/time formatted as relative or short date (reuse similar logic to dashboard formatLastStudied, but for history use a more explicit format: "Feb 11, 14:30" or "11 feb, 14:30" based on locale)
- Center: repository label (session.repositoryName or t('history.allRepos'))
- Right side: score as "X/Y" with color coding (green if >= 70%, yellow if >= 40%, red otherwise) and duration below it

Use a simple date formatting approach:
```typescript
function formatSessionDate(dateString: string): string {
  const date = new Date(dateString);
  return date.toLocaleDateString(undefined, {
    month: 'short',
    day: 'numeric',
    hour: '2-digit',
    minute: '2-digit',
  });
}

function formatDuration(totalSeconds: number): string {
  const minutes = Math.floor(totalSeconds / 60);
  const seconds = totalSeconds % 60;
  if (minutes === 0) return `${seconds}s`;
  return `${minutes}m ${seconds}s`;
}
```

Style the list using `StyleSheet.create` matching the existing app patterns (surface cards, rounded corners, theme colors, etc.). Each row should be a card-like surface with subtle elevation, similar to StatCard or the stats card in StudySummaryScreen.

Row layout:
```
[date/time]     [repo name]     [score]
                                [duration]
```

Use Ionicons for visual accents: `checkmark-circle` for high scores, `alert-circle` for medium, `close-circle` for low.

Support pull-to-refresh via `RefreshControl` on the FlatList.
