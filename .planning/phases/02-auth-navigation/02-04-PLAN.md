      2. Tagline: "Your flashcards, supercharged" in gray (#6B7280)
      3. Google Sign-In button (using GoogleSigninButton from the SDK)

    **State:**
    - isLoading: boolean (shows ActivityIndicator during sign-in)
    - error: string | null (shows error message if sign-in fails)

    **handleSignIn function:**
    ```typescript
    const handleSignIn = async () => {
      setIsLoading(true);
      setError(null);
      try {
        await signInWithGoogle();
        // Navigation happens automatically via AuthContext state change
      } catch (e: any) {
        setError(e.message || 'Sign in failed');
      } finally {
        setIsLoading(false);
      }
    };
    ```

    - Use GoogleSigninButton from @react-native-google-signin/google-signin
    - Size: GoogleSigninButton.Size.Wide
    - Color: GoogleSigninButton.Color.Dark
    - onPress: handleSignIn
    - Disabled when isLoading

    **When isLoading:**
    - Show ActivityIndicator instead of the button (color '#3B82F6', size 'large')

    **Error display:**
    - If error is not null, show Text with error message in red (#ef4444) above the button

    **Export:** Named export LoginScreen
