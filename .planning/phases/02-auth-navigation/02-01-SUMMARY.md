## Decisions Made
- **SecureStore over AsyncStorage:** Encrypted storage is essential for auth tokens on Android
- **Web Client ID for configuration:** Google Sign-In requires the Web Client ID (not Android Client ID) for Supabase's signInWithIdToken to work
- **Warning instead of throwing:** configureGoogleSignIn logs a warning if env var is missing, allowing testing of other features
