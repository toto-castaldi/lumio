<task type="auto">
  <name>Task 1: Create AuthContext with Google Sign-In integration</name>
  <files>apps/android/contexts/AuthContext.tsx</files>
  <action>
    Create `apps/android/contexts/AuthContext.tsx` implementing the complete auth lifecycle.

    **Types:**
    ```typescript
    type AuthState = 'loading' | 'logged_out' | 'ready';

    interface AuthContextType {
      user: User | null;
      session: Session | null;
      state: AuthState;
      signInWithGoogle: () => Promise<void>;
      signOut: () => Promise<void>;
    }
    ```

    **AuthProvider implementation:**
    1. State: user, session, state (starts as 'loading')
    2. useEffect on mount:
       - Call configureGoogleSignIn() from lib/auth.ts
       - Call supabase.auth.getSession() to restore persisted session
       - Subscribe to supabase.auth.onAuthStateChange
       - Set state to 'ready' if session exists, 'logged_out' if not
       - Return cleanup: unsubscribe from onAuthStateChange

    3. signInWithGoogle function:
       - Call GoogleSignin.hasPlayServices() first
       - Call GoogleSignin.signIn()
       - Check response.type === 'success' && response.data.idToken
       - Call supabase.auth.signInWithIdToken({ provider: 'google', token: idToken })
       - Handle errors:
         - statusCodes.SIGN_IN_CANCELLED: return silently (user cancelled)
         - statusCodes.PLAY_SERVICES_NOT_AVAILABLE: throw Error('Google Play Services not available')
         - Other errors: rethrow

    4. signOut function:
       - Call GoogleSignin.signOut()
       - Call supabase.auth.signOut()
       - No confirmation (per CONTEXT decisions)

    **Export:**
    - AuthProvider component
    - useAuth hook (throws if used outside provider)
  </action>
