  <action>
1. Create `useHaptics.ts` hook:
   - Import `* as Haptics from 'expo-haptics'`
   - Export `useHaptics()` returning `{ correctFeedback, incorrectFeedback }`
   - `correctFeedback`: calls `Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success)` (light tap)
   - `incorrectFeedback`: calls `Haptics.notificationAsync(Haptics.NotificationFeedbackType.Error)` (heavier buzz)
   - Wrap in try/catch silently (haptics may not work on emulator per Pitfall 6 in research)

2. Create `AnswerOption.tsx`:
   - Props: `{ label: string; text: string; onPress: () => void; state: 'default' | 'selected' | 'correct' | 'incorrect' | 'dimmed'; disabled: boolean }`
   - TouchableOpacity with rounded corners (borderRadius: 16)
   - Left side: circular label badge (A/B/C/D) with state-dependent colors:
     - `default`: gray bg, dark text
     - `selected`: primary bg, white text (before answer confirmed)
     - `correct`: green bg (#10b981), white checkmark icon
     - `incorrect`: red bg (#ef4444), white X icon
     - `dimmed`: light gray, reduced opacity
   - Right side: option text
   - Border changes by state: default=gray, correct=green, incorrect=red, dimmed=lighter gray
   - Background: default=white/surface, correct=green-50, incorrect=red-50
   - Use `useTheme()` for dark mode compatibility
   - Use Ionicons for check/close icons in answered states

3. Create `ExplanationPanel.tsx`:
   - Props: `{ isCorrect: boolean; explanation: string; userVote: QuestionVote | null; onVote: (vote: QuestionVote) => void; isVoting: boolean }`
   - Container with green (#10b981) border for correct, red (#ef4444) border for incorrect
   - Top row: result icon (checkmark/X in circle) + "Correct!" or "Incorrect" text
   - Body: explanation text (whitespace preserved, pre-wrap style)
   - Vote section (per locked decision: inline, alongside explanation, not separate):
     - Label: "Was this question helpful?"
     - Two buttons: thumbs-up (like) and thumbs-down (dislike)
     - Active state: filled/highlighted when user has voted
     - Use Ionicons: `thumbs-up` / `thumbs-up-outline`, `thumbs-down` / `thumbs-down-outline`
     - Disable both buttons while `isVoting` is true
   - Use `useTheme()` for dark mode colors

4. Create `ProgressBar.tsx`:
   - Props: `{ progress: number; current: number; total: number }`
   - Horizontal bar (height: 4px) with rounded corners, primary color fill
   - Text below or beside: "{current} / {total}" fraction display
   - `progress` is 0-to-1 float, bar width = progress * container width
   - Use `useTheme()` for colors: bar track = border color, fill = primary

5. Create `QuizCard.tsx`:
   - Props: `{ card: StudyCard; question: ShuffledQuestion; userAnswer: string | null; userVote: QuestionVote | null; onAnswer: (answer: string) => void; onVote: (vote: QuestionVote) => void; isVoting: boolean }`
   - ScrollView container (for long questions with explanation)
   - Card title (smaller, secondary text)
   - Question text (prominent, larger font)
   - 4 AnswerOption components mapped from `question.options`
   - Compute each option's state:
     - Before answer: all 'default'
     - After answer: correct answer gets 'correct', user's wrong answer gets 'incorrect', others get 'dimmed'
   - When user taps an option (before answering): call `onAnswer(label)`, trigger haptic feedback via `useHaptics()` (correctFeedback if correct, incorrectFeedback if wrong)
   - After answering: show ExplanationPanel below the options
   - Disable option tapping after answer is submitted

   - Show toast "Card skipped" via react-native-toast-message

   - When `session.state === 'studying'`, prevent navigation and show `Alert.alert`:
     - Title: "End Session?"
     - Message: "Your progress will be saved."
