Build the WebView-based card content renderer that displays markdown with syntax-highlighted code blocks, LaTeX formulas, and Supabase-hosted images with pinch-to-zoom support.

Purpose: This implements CARD-01 through CARD-05 requirements. Card content in Lumio uses full markdown with LaTeX math and code blocks -- these cannot be rendered with native React Native text components. A WebView with CDN-loaded KaTeX, highlight.js, and marked.js provides complete rendering support with minimal native dependencies.

Output: CardContentView component that takes markdown content and renders it in a themed WebView with auto-sizing height, plus a "View Card" button in StudyScreen that opens the card content in a modal.

1. Create `cardHtml.ts` -- generates self-contained HTML for WebView rendering:
   - Export `generateCardHtml(markdownContent: string, isDark: boolean): string`
   - The HTML must include (via CDN script/link tags):
     - `marked@12.0.0` for markdown parsing
     - `katex@0.16.9` CSS + JS + auto-render extension for LaTeX
     - `highlight.js@11.9.0` JS + theme CSS (github-dark for dark mode, github for light mode)
   - Viewport meta: `width=device-width, initial-scale=1.0, maximum-scale=5.0` (enables pinch-to-zoom per locked decision: images MUST be zoomable)
   - Body styles:
     - Font: system-ui/-apple-system
     - Font size: 16px, line-height: 1.6
     - Colors: text and bg from theme (pass isDark boolean)
     - Dark bg: #1f2937, dark text: #f9fafb
     - Light bg: #ffffff, light text: #1f2937
   - Additional CSS:
     - `img`: max-width 100%, height auto, border-radius 8px, margin 8px 0
     - `pre`: overflow-x auto, border-radius 8px, padding 12px, font-size 14px
     - `code`: font-family SF Mono/Menlo/monospace, font-size 14px
     - `table`: border-collapse, full width, themed borders
     - `blockquote`: left border, themed colors
     - `h1-h4`: proper margins
     - `a`: blue (#3b82f6)
     - `.katex-display`: overflow-x auto (for wide formulas)
   - Script execution order (at bottom of body):
     1. Parse markdown: `document.getElementById('content').innerHTML = marked.parse(content)`
     2. Render LaTeX: `renderMathInElement(document.body, { delimiters: [$$, $], throwOnError: false })`
     3. Highlight code: `hljs.highlightAll()`
     4. After 100ms timeout, report height to RN: `window.ReactNativeWebView.postMessage(JSON.stringify({ type: 'height', value: document.body.scrollHeight }))`
   - Use `JSON.stringify(markdownContent)` to safely embed content in the JS
   - IMPORTANT: escape `</script>` inside template literals as `<\/script>` to prevent premature closing

2. Create `CardContentView.tsx`:
   - Props: `{ content: string; isDark: boolean; style?: ViewStyle }`
   - Import `WebView` from 'react-native-webview'
   - Import `generateCardHtml` from '../lib/cardHtml'
   - State: `webViewHeight: number` (starts at 300 as default)
   - Render WebView with:
     - `source={{ html: generateCardHtml(content, isDark) }}`
     - `style={{ height: webViewHeight, ...style }}` (dynamic height)
     - `scrollEnabled={false}` -- let parent ScrollView handle scrolling (avoids nested scroll issues)
     - `originWhitelist={['*']}` -- allow CDN loading
     - `javaScriptEnabled={true}`
     - `onMessage` handler: parse `event.nativeEvent.data`, if `type === 'height'`, set `webViewHeight` to the value (add small padding, e.g., value + 20)
     - `scalesPageToFit={false}` on Android (content already sized correctly)
     - No `onShouldStartLoadWithRequest` -- allow CDN requests
   - Memoize the HTML generation with `useMemo` based on `content` and `isDark` to avoid re-rendering on every parent update
  </action>
