1. Create `useStudySession.ts` hook following the PWA pattern in apps/mobile/src/pages/StudyPage.tsx:

   Define types:
   ```typescript
   type StudyState = 'loading' | 'no_cards' | 'studying' | 'completed';

   interface AnsweredCard {
     card: StudyCard;
     question: ShuffledQuestion;
     userAnswer: string;
     isCorrect: boolean;
     vote: QuestionVote | null;
   }

   interface StudySessionState {
     state: StudyState;
     cards: StudyCard[];
     currentIndex: number;
     currentCard: StudyCard | null;
     currentQuestion: ShuffledQuestion | null;
     userAnswer: string | null;
     userVote: QuestionVote | null;
     answeredCards: AnsweredCard[];
     skippedCount: number;
     startedAt: Date;
     repositoryMap: Map<string, Repository>;
   }
   ```

   The hook should expose:
   - `session` (StudySessionState)
   - `isLoadingQuestion: boolean`
   - `isSkipping: boolean`
   - `isVoting: boolean`
   - `handleAnswer(answer: string): void` -- sets userAnswer, does NOT advance
   - `handleVote(vote: QuestionVote): Promise<void>` -- calls voteQuestion from @lumio/core
   - `handleSkip(): Promise<void>` -- marks card as skipped, loads next
   - `handleNext(): Promise<void>` -- saves answered card to answeredCards, loads next card
   - `handleGoToCard(index: number): void` -- navigate to previously answered card for review
   - `cardsRemaining: number` -- computed from total cards minus seen cards
   - `progress: number` -- 0 to 1 fraction for progress bar

   Implementation details:
   - On mount, call `getUserRepositories()` and `getStudyCardsWithQuestions()` in parallel
   - Filter cards through Deck class per repository (same pattern as PWA StudyPage)
   - If no filtered cards, set state to 'no_cards'
   - Otherwise set state to 'studying' but DON'T auto-load the first question yet
   - `handleNext()` should call `getPreGeneratedQuestion(card.id)` for the next unseen card
   - If a card has no pre-generated question, silently skip it and try the next
   - When all cards exhausted, set state to 'completed'
   - Track answered cards in `answeredCards` array for summary screen and for back-navigation/review
   - `handleGoToCard(index)` sets currentIndex to the given index and shows that card's stored question/answer (for review of previously answered cards)
   - Import types from @lumio/core: `StudyCard`, `ShuffledQuestion`, `QuestionVote`, `Repository`, `Deck`, `getStudyCardsWithQuestions`, `getUserRepositories`, `getPreGeneratedQuestion`, `voteQuestion`

     - `studying` with currentQuestion: Placeholder View with question text and "Quiz UI coming in Plan 02" text (will be replaced)

   - Use `useTheme()` for colors, style with theme-aware colors
   - Use `useNavigation()` with `NativeStackNavigationProp<RootStackParamList>` for back navigation
